# 配置与数据源

TVBox 的全部内容都由一个 JSON「配置地址」驱动，入口在 `设置 → 配置地址`。核心代码：`app/src/main/java/com/github/tvbox/osc/api/ApiConfig.java`。

## 1. 配置地址

### 1.1 填写方式

配置地址对话框（`ui/dialog/ApiDialog.java`）里可以同时填写 4 项：

- **配置地址**：点播配置 JSON；
- **直播地址**：可单独指定，覆盖配置里的 `lives`；
- **EPG 地址**：节目单接口；
- **代理地址**：会被保存，但当前代码中没有其他地方读取它。

配置、直播、EPG 地址各自保留**历史列表**，可从历史里快速切换。对话框里还会显示一个二维码，用手机扫码就能在浏览器里远程填写地址（见 [09-远程控制与推送](09-远程控制与推送.md)）。

### 1.2 支持的地址格式

| 格式 | 说明 |
| --- | --- |
| `http(s)://...` | 网络配置 |
| 不带协议的地址 | 自动补上 `http://` |
| `clan://localhost/xxx` | 本地存储卡上的文件 |
| `file://xxx`、`./xxx` | 输入时自动转换成 `clan://localhost/xxx` |
| `地址;pk;密钥` | 加密配置，用 `;pk;` 后面的密钥做 AES-ECB 解密 |

### 1.3 加密 / 包裹格式

`ApiConfig.FindResult()` 能自动识别以下内容：

- 本身就是明文 JSON：直接使用；
- **图片包裹**：内容中有 `xxxxxxxx**` 标记（8 位字母），标记后的部分按 Base64 解码；
- **AES-CBC**：以 `2423` 开头的十六进制内容，从内容里取 key 和 iv 解密；
- **AES-ECB**：地址带 `;pk;密钥` 时，用该密钥解密。

### 1.4 缓存与容错

- 解析成功的配置按地址的 MD5 缓存到应用私有目录，启动时可以先用缓存，加快首页加载；
- 网络请求失败时自动回退到本地缓存。

## 2. 站点（sites）

每个站点在配置 `sites`（或 `video.sites`）数组中描述，加载为 `SourceBean`。

### 2.1 站点类型 `type`

| type | 说明 |
| --- | --- |
| `0` | 苹果CMS **XML** 接口（`ac=videolist`） |
| `1` | 苹果CMS **JSON** 接口（`ac=detail`） |
| `3` | **爬虫（Spider）**，由 Jar / JS / Python 实现，见下文 |
| `4` | **远程 T4 接口**：HTTP 接口，以 `filter`、`extend`、`ac`、`ids` 等参数请求 |

### 2.2 站点字段

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `key` | 必填 | 站点唯一标识；以 `py_` 开头的站点默认不可筛选 |
| `name` | 同 key | 显示名称 |
| `type` | 必填 | 见上表 |
| `api` | 必填 | 接口地址或爬虫类名 / 脚本地址 |
| `searchable` | 1 | 是否参与搜索 |
| `quickSearch` | 1 | 是否参与详情页快搜 |
| `filterable` | 1 | 是否支持分类筛选 |
| `hide` | 0 | 是否在站点列表中隐藏 |
| `playUrl` | 空 | 站点自带的解析地址，支持 `json:` / `parse:解析名` 前缀 |
| `ext` | 空 | 传给爬虫的扩展参数 |
| `jar` | 空 | 站点单独使用的 Jar（不填则用全局 `spider`） |
| `playerType` | -1 | 站点指定播放器（-1 表示使用全局设置） |
| `categories` | 空 | 只显示列出的分类 |
| `click` | 空 | 嗅探时要模拟点击的元素选择器 |
| `style` | 空 | 海报样式，如 `{"type":"rect","ratio":1.33}`，type 可为 rect / list 等 |

### 2.3 爬虫引擎

`ApiConfig.getCSP()` 按 `api` 的后缀选择引擎：

| 条件 | 引擎 | 实现 |
| --- | --- | --- |
| `api` 以 `.js` 结尾或含 `.js?` | **JS 爬虫**，运行在 QuickJS（`:quickjs` 模块） | `catvod/crawler/JsLoader.java`、`util/js/` |
| `api` 含 `.py` | **Python 爬虫**，只有 `python` 构建变体可用（Chaquopy，`:pyramid` 模块） | `app/src/python/.../pyLoader.java` |
| 其他 | **Jar 爬虫**（DexClassLoader 加载） | `catvod/crawler/JarLoader.java` |

Jar 加载的特点：

- 支持全局 `spider` 和站点单独的 `jar`，可以同时加载多个 Jar；
- 地址格式支持 `地址;md5;校验值`：本地缓存的 MD5 一致时直接用缓存，不重新下载；
- 支持图片包裹的 Jar；
- Jar 常驻缓存，可以手动清理（首页点 App 名称）；长时间没有手动清理时会自动清理（带 md5 的除外）；
- 配置项 `jarCache` 控制是否启用 Jar 缓存；
- Jar 加载失败时立即改用上一次缓存的 Jar。

## 3. 其他配置字段

| 字段 | 说明 |
| --- | --- |
| `spider` | 全局爬虫 Jar 地址 |
| `wallpaper` | 壁纸地址，可在设置里「换张壁纸」 |
| `jarCache` | 是否缓存 Jar，默认 `"true"` |
| `parses` | 解析接口列表，见 [06-解析嗅探与去广告](06-解析嗅探与去广告.md) |
| `flags` | 需要走解析的线路标识（VIP 线路） |
| `lives` | 直播源，见 [07-直播](07-直播.md) |
| `livePlayHeaders` | 直播请求头，可以按线路 flag 匹配 |
| `rules` | 嗅探 / 过滤 / 去广告 / 点击脚本规则 |
| `ads` | 需要拦截的广告域名（会和内置列表合并） |
| `ijk` | IJK 播放器参数分组（软解 / 硬解等），不配置时使用内置默认值 |

## 4. 首页数据源

- `设置 → 数据源` 可以切换首页使用的站点；首页按遥控器 **菜单键** 也能弹出站点切换；
- `设置 → 数据源显示` 控制首页是否显示当前站点名称；
- 内置的 `push_agent` 站点用于接收推送链接（见 [09-远程控制与推送](09-远程控制与推送.md)）。
