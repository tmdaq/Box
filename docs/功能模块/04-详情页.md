# 详情页

核心代码：`ui/activity/DetailActivity.java`、`ui/fragment/PlayFragment.java`（预览窗口播放器）、`bean/VodInfo.java`。

## 1. 影片信息

- 展示海报、片名、年份、站点、地区、语言、类型、演员、导演和简介；
- 点击简介弹出完整内容对话框（`DescDialog`），**长按简介**复制简介文字到剪贴板；
- 点击「播放地址」把当前集的原始播放地址复制到剪贴板。

## 2. 线路与选集

- **线路（播放源 flag）**：横向列表，切换后选集列表随之刷新；切换线路时会尽量保持当前集数；
- **选集分组**：集数较多时自动分组，每组大小随总集数变化：

  | 总集数 | 每组集数 |
  | --- | --- |
  | ≤ 100 | 20 |
  | 101 ~ 300 | 30 |
  | 301 ~ 500 | 50 |
  | 501 ~ 1000 | 100 |
  | 1001 ~ 1500 | 150 |
  | 1501 ~ 2500 | 200 |
  | > 2500 | 300 |

- 选集列表宽度会根据集名长度自动调整；
- 正在播放的集会高亮，播放器切集时详情页同步刷新。

### 正序 / 倒序

- 「倒序」按钮切换选集排列顺序，按钮文字在「倒序 / 正序」之间切换，排序状态会写入观看历史；
- 加载数据时会检查不超过 300 集的选集列表：如果集名数字是递减的（倒着排），就自动改成正序；
- 倒序状态下，播放器里的「上一集 / 下一集」和自动播放下一集都按**当前列表顺序**切换。

## 3. 窗口预览

`设置 → 窗口预览` 打开时（默认开启），详情页右侧内嵌一个小窗播放器（`PlayFragment`）：

- 进入详情页后自动开始播放；
- 点「全屏」或点击预览窗口切换到全屏，全屏时禁用详情页按钮的焦点，避免遥控器按键跑到后面；
- 在小窗中点选集会直接全屏播放（代码中有注释，可以改成不全屏）；
- 关闭窗口预览时，点「播放」或海报进入独立的全屏播放页（`PlayActivity`）。

## 4. 操作按钮

| 按钮 | 功能 |
| --- | --- |
| 播放 / 全屏 | 开始播放或切换全屏 |
| 快搜 | 到其他站点搜同名资源，见 [03-搜索](03-搜索.md) |
| 倒序 / 正序 | 切换选集顺序 |
| 推送 | 把当前影片推送到局域网内另一台 TVBox（填写对方 IP 和端口），对方会直接打开同一部影片的详情页 |
| ★ 收藏 | 加入 / 取消收藏 |

## 5. 历史记录

- 进入详情页会读取历史记录，恢复上次的线路、集数、排序状态和播放器配置；
- 播放过程中自动保存观看历史。

## 6. 外部打开详情页

系统广播 `android.content.movie.detail.Action`（附带 `id`、`sourceKey`）可以直接打开指定影片的详情页（`receiver/DetailReceiver.java`）。
