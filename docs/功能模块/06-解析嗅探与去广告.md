# 解析、嗅探与去广告

很多站点返回的不是能直接播放的地址，而是网页地址或需要解析的 VIP 链接。TVBox 用「解析接口 + WebView 嗅探」把它们转换成真实的视频地址。

核心代码：`ui/activity/PlayActivity.java`（`doParse`、`initParse`、WebView 部分）、`util/parser/SuperParse.java`、`util/VideoParseRuler.java`、`util/AdBlocker.java`、`util/M3U8.java`。

## 1. 什么时候走解析

站点（爬虫）的播放结果里有：

- `parse`：为 `1`（默认）时需要解析 / 嗅探；
- `jx`：为 `1` 时强制使用配置里的解析接口；
- `playUrl`：站点自带的解析前缀；
- `url`、`header`、`flag`、`subt`/`subs`（字幕）、`danmaku`（弹幕）。

判断逻辑：

1. `parse=0` 且 `jx=0`：直接播放 `playUrl + url`；
2. `jx=1`，或线路 `flag` 在配置的 `flags`（VIP 线路）里且站点没有自带 `playUrl`：使用**默认解析接口**，播放时可以在控制栏切换其他解析；
3. 否则使用站点 `playUrl`：
   - `json:地址`：按 JSON 解析处理；
   - `parse:解析名`：使用配置里同名的解析接口；
   - 其他：当作 Web 嗅探地址。

## 2. 解析接口类型（`parses[].type`）

| type | 名称 | 说明 |
| --- | --- | --- |
| 0 | Web 嗅探 | 在隐藏的 WebView 中打开「解析地址 + 视频地址」，拦截网络请求找出视频地址 |
| 1 | JSON 解析 | 请求接口，从返回的 `url`（或 `data.url`）取地址，同时读取 `user-agent`、`referer` |
| 2 | JSON 扩展 | 把多个 JSON 解析合在一起交给爬虫的 `jsonExt` 处理 |
| 3 | JSON 聚合 | 调用爬虫的 `jsonExtMix`，同时混合 JSON 解析和 Web 解析 |
| 4 | 超级解析 | 内置聚合解析（`SuperParse`）：并发请求配置里所有 JSON / Web 解析，取最先成功的结果 |

- App 内置了一个名为「超级解析」的解析项；
- `设置 → 默认解析` 可以选默认解析接口；
- 解析可以带 `ext` 扩展参数（JSON 对象）。

## 3. WebView 嗅探

- `设置 → 嗅探Webview` 可选「系统自带」或 **XWalkView**（Crosswalk，第一次使用时需要下载运行组件，适合低版本 Android；Android 5.0 以上建议用系统 WebView）；
- 嗅探时拦截页面请求，用规则判断哪个请求是视频地址，找到后自动停止嗅探并开始播放；
- 嗅探到的多个候选地址会排队，当前地址播放失败时依次尝试下一个；
- 广告域名的请求直接返回空响应；
- 打开**调试模式**后嗅探 WebView 会显示在前台，并加载图片，方便排查。

### 嗅探判断顺序

1. 地址包含 `url=http` 或 `.html` 时不算视频；
2. 爬虫开启 `manualVideoCheck` 时，交给爬虫的 `isVideoFormat` 判断；
3. 否则交给 `VideoParseRuler`：先用通用规则判断是不是视频格式；不是的话，再用当前页面域名对应的 `rules`（没有对应域名时用 `host` 为 `*` 的通配规则）匹配。

## 4. 规则配置（`rules`）

```json
"rules": [
  { "host": "www.example.com", "rule": ["mp4", ".m3u8"], "filter": ["ad.m3u8"] },
  { "hosts": ["example1", "example2"], "regex": ["#EXT-X-DISCONTINUITY\\r*\\n*#EXTINF:6.4,[\\s\\S]*?#EXT-X-DISCONTINUITY"] },
  { "name": "剧圈圈", "hosts": ["jqqzx"], "script": ["document.getElementById('playleft').children[0].contentWindow.document.getElementById('start').click()"] }
]
```

| 字段 | 作用 |
| --- | --- |
| `host` + `rule` | 该域名下嗅探时，请求地址匹配 rule 中所有正则才算视频；`host` 可以写 `*` 作为通配 |
| `host` + `filter` | 该域名下匹配 filter 的请求会被排除 |
| `hosts` + `regex` | 对这些域名的 M3U8 用正则删除广告片段 |
| `hosts` + `script` | 嗅探页面加载完成后执行的 JS（比如模拟点击播放按钮） |

站点字段 `click` 和 `script` 规则作用相同，写法是 `域名关键字;JS代码` 或直接写 JS 代码，优先级比 `rules.script` 高。

## 5. 广告过滤

### 5.1 广告域名拦截

- 内置一份广告域名列表，配置里的 `ads` 会合并进来；
- 在 WebView 嗅探中命中这些域名的请求直接返回空响应。

### 5.2 M3U8 去广告（`设置 → 广告过滤`，默认开启）

播放 m3u8 地址（或本地代理地址）时：

1. 先下载 m3u8 内容（如果是多码率的主列表，会再请求一次子列表）；
2. `M3U8.purify()` 分析切片：
   - 统计各切片地址的前缀，**删掉占比很少的「异类」切片**（通常是插播广告）；
   - 识别 `#EXT-X-DISCONTINUITY` 等标记包围的广告段；
   - 按 `rules.regex` 删除匹配的片段；
3. 净化后的内容通过本地服务 `http://127.0.0.1:9978/m3u8` 交给播放器。

开启 `设置 → 预缓存` 时，净化后的内容还会再把分片地址改写到本地分片代理 `/hlsseg`，再交给播放器。广告过滤关闭，或者没有识别出广告时，也会对原始内容做这一步改写。详见「点播播放器 · HLS 预缓存」。

## 6. 特殊链接直接播放

代码：`util/thunder/Thunder.java`、`util/thunder/Jianpian.java`（依赖 `app/libs/thunder.jar`，迅雷 SDK）。

| 链接类型 | 处理方式 |
| --- | --- |
| `magnet:` 磁力 | 迅雷 SDK 解析种子，列出视频文件后边下边播 |
| `thunder://` 迅雷 | 同上 |
| `ed2k://` 电驴 | 同上 |
| `.torrent` 种子 | 同上 |
| `ftp://` | 迅雷下载任务播放 |
| `xg://`、`xgplay://`、`tvbox-xg:` 荐片 | 转换成 FTP 地址后播放 |
| `tvbox-drive://` | 存储空间里的文件，直接播放（可带认证请求头） |
| 部分分段 mp4（`ziyuantt.com` 带 `&url=a|b|c`） | 按分段依次播放 |

## 7. 安全 DNS

`设置 → 安全DNS` 可以给全局网络请求开启 DNS over HTTPS：腾讯、阿里、360、Google、AdGuard、Quad9。本地服务还提供 `/dns-query` 端点，可以把 DoH 查询转发给爬虫等使用。
