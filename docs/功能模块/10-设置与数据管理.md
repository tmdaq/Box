# 设置与数据管理

核心代码：`ui/activity/SettingActivity.java`、`ui/fragment/ModelSettingFragment.java`、`util/HawkConfig.java`（所有设置键）、`base/App.java`（默认值）。

设置使用 Hawk 保存在 SharedPreferences 中；历史、收藏、搜索历史、存储空间等数据保存在 Room 数据库中（`data/AppDataBase.java`）。

## 1. 设置项

设置页分成「首页」「播放器」「系统」三组。

### 1.1 首页

| 设置项 | 可选值（默认值加粗） | 说明 |
| --- | --- | --- |
| 配置地址 | — | 填写配置 / 直播 / EPG / 代理地址，见 [01-配置与数据源](01-配置与数据源.md) |
| 配置历史 | — | 从历史配置中切换 |
| 数据源 | 配置中未隐藏的站点 | 首页使用的站点 |

| 推荐 | 豆瓣热播 / **站点推荐** / 观看历史 | 首页第一页内容 |

### 1.4 隐藏设置：调试模式

在设置页用遥控器快速连按数字键 **0** 四次（每次间隔不超过 200ms），会出现「调试模式」开关。打开后，解析嗅探的 WebView 会显示在前台并加载图片，方便排查解析问题。

## 2. 观看历史

`ui/activity/HistoryActivity.java`、`cache/VodRecord*.java`、`util/HistoryHelper.java`

- 自动记录影片、线路、集数、播放进度、排序状态、播放器配置；
- 保留条数由「历史条数」控制；
- 支持删除单条（删除模式）和清空全部（需要确认）；
- 首页推荐选「观看历史」时也能长按删除。

## 3. 收藏夹

`ui/activity/CollectActivity.java`、`cache/VodCollect*.java`

- 在详情页「★ 收藏」添加 / 取消；
- 收藏夹支持删除单条和清空全部。

## 4. 数据备份与还原

`ui/dialog/BackupDialog.java`

- 「立即备份」会在存储卡的 `tvbox_backup/<yyyy-MM-dd-HHmmss>/` 下保存：
  - `sqlite`：Room 数据库（历史、收藏、存储空间等）；
  - `hawk`：全部设置项（包括加密密钥）；
- 备份列表中点选某个备份即可还原，还原后 App 自动重启；
- 可以删除旧备份；
- 需要存储权限。

## 5. 重置

`设置 → 重置`，确认后清除 App 的公共和私有数据（配置、缓存、数据库等），然后自动重启。

## 6. 缓存清理

- 首页点 App 名称：清空缓存目录，并删除当前站点的 Jar 缓存后重新加载；
- Jar 缓存长时间不手动清理时会自动清理（带 md5 校验的 Jar 除外）。
