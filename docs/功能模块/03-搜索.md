# 搜索

核心代码：`ui/activity/SearchActivity.java`、`ui/activity/FastSearchActivity.java`、`ui/dialog/QuickSearchDialog.java`、`ui/dialog/SearchCheckboxDialog.java`。

## 1. 搜索页

- 内置屏幕键盘（`ui/tv/widget/SearchKeyboard`），方便用遥控器输入；
- **热门搜索**：打开搜索页时从腾讯视频热搜接口拉取热门词；
- **输入联想**：输入时请求联想接口，实时给出候选词；
- **搜索历史**：保存在本地数据库（`cache/SearchHistory`），可以清空；
- **远程搜索**：页面上显示二维码，手机扫码后可以在浏览器里输入搜索词，盒子会自动开始搜索（见 [09-远程控制与推送](09-远程控制与推送.md)）。

### 搜索范围

点击搜索源按钮可以选择：

- **全局搜索**：搜索所有 `searchable=1` 的站点；
- **默认源**：只搜首页当前站点；
- **指定站点**：只搜某个站点。

另外可以在「选择搜索源」对话框中**勾选参与搜索的站点**（支持全选 / 全不选），勾选结果会保存下来。

### 结果展示

`设置 → 搜索展示` 可选：

- **文字列表**
- **缩略图**（默认）

## 2. 聚搜（FastSearch）

打开 `设置 → 聚搜` 后，搜索结果会进入聚搜页面：

- 左侧按**站点分组**列出命中的站点，右侧显示该站点的结果，也可以选择「全部显示」；
- 搜索时先对片名做**分词**，再用分出的关键词筛选结果，结果更精准；
- 长按首页推荐中的影片也会直接用片名进入聚搜。

## 3. 详情页快搜

详情页的「快搜」按钮（`QuickSearchDialog`）：

- 用当前影片名到其他 `quickSearch=1` 的站点搜索同名资源；
- 片名先分词，可以点选不同关键词重新筛选；
- 自动去掉当前这部影片本身；
- 方便在当前线路不可用时换到别的站点播放。

## 4. 外部触发搜索

- 系统广播 `android.content.movie.search.Action`（附带 `title`）会打开搜索页，并用该标题直接搜索（`receiver/SearchReceiver.java`）；
- 通过远程控制网页提交的搜索词，走同样的流程。
