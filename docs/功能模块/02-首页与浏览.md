# 首页与浏览

核心代码：`ui/activity/HomeActivity.java`、`ui/fragment/UserFragment.java`（首页推荐页）、`ui/fragment/GridFragment.java`（分类列表页）。

## 1. 顶部栏

| 元素 | 点击 | 长按 |
| --- | --- | --- |
| App 名称 / 站点名称 | 清除缓存目录并清理当前站点 Jar 缓存，然后重新加载首页 | 直接重新加载首页 |
| Wi-Fi 图标 | 打开系统 Wi-Fi 设置 | — |
| 搜索 | 进入搜索页 | — |
| 样式 | 首页推荐列表在「单行 / 多行」两种排布间切换 | — |
| 应用抽屉 | 进入「我的应用」 | — |
| 设置 | 进入设置页 | 打开系统里本应用的详情设置 |
| 日期时间 | 打开系统日期设置 | — |

- 打开「数据源显示」后，顶部会显示当前首页站点名称，否则显示 App 名称；
- 首页按遥控器**菜单键**，或在「首页」标签上再按一次确定，会弹出站点切换列表；
- 列表往下滚动时顶部栏会自动收起；
- 首页连按两次返回键退出应用。

## 2. 首页推荐（第一个标签页）

由 `设置 → 推荐` 决定内容来源：

| 选项 | 说明 |
| --- | --- |
| 豆瓣热播 | 从豆瓣拉取当年可播放的热门影片 |
| 站点推荐 | 首页站点 `homeContent` 返回的推荐列表（默认） |
| 观看历史 | 最近观看记录，条数由「历史条数」控制 |

交互：

- 选「观看历史」时，长按某条记录进入**删除模式**，再点击即可删除记录；
- 长按豆瓣 / 站点推荐中的影片，会直接用片名做**聚搜**；
- 首页快捷入口：直播、搜索、推送、文件（存储空间）、收藏、历史、设置；
- 长按「历史」入口，首页推荐会按 豆瓣热播 → 站点推荐 → 观看历史 的顺序切到下一种，并重新加载首页。

## 3. 分类与筛选

- 首页顶部的分类标签来自站点的分类列表，配置了 `categories` 时只显示指定分类；
- 有筛选条件的分类，在已选中的标签上再按确定会弹出**筛选对话框**（`ui/dialog/GridFilterDialog.java`），可以组合多个条件；已选的筛选条件数量会显示在标签图标上；
- 分类列表支持分页加载更多。

### 列表展示模式

`GridFragment` 根据分类数据的 flag 决定展示方式：

- **普通模式**：海报网格；
- **文件夹模式**：可以逐级进入子目录（适合网盘类爬虫）；
- **带缩略图的文件夹模式**。

站点配置了 `style`（如 `{"type":"rect","ratio":0.75}`）时，会按指定的宽高比和类型（rect / list 等）调整海报尺寸和每行个数。

## 4. 壁纸

- `设置 → 换张壁纸`：下载配置里 `wallpaper` 指定的图片作为背景；
- `设置 → 重置壁纸`：恢复默认背景。

## 5. 启动直接进入直播

打开 `设置 → 启动时进直播` 后，App 启动加载完配置会直接进入直播页面。

## 6. 我的应用

`ui/activity/AppsActivity.java`：列出设备上已安装的应用，可以直接启动；进入删除模式后可以卸载选中的应用，相当于一个简单的电视桌面应用抽屉。
