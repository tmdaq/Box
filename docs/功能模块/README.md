# TVBox 功能模块总览

TVBox（包名 `com.github.tvbox.osc.tk`）是一款面向 Android 电视盒子 / 手机的**影视聚合播放器**。软件本身不提供任何影视内容，所有数据都来自用户填写的「配置地址」：配置里描述了点播站点、解析接口、直播源、去广告规则等，App 负责加载、展示和播放。

> 本目录内容根据当前 `main` 分支源码整理（最近提交：`258a5fe 系统播放器增加音轨选择`）。

## 功能一览

- **配置驱动**：支持 http / 本地 `clan://` 配置地址，支持 Base64 图片包裹与 AES 加密配置，配置与爬虫 Jar 均带本地缓存，网络失败时自动回退缓存。
- **多种站点类型**：苹果CMS XML(0) / JSON(1) 接口、爬虫(3，Jar / JS / Python)、远程 T4 接口(4)。
- **首页**：分类标签 + 筛选、站点自定义海报样式、文件夹模式；首页推荐可选「豆瓣热播 / 站点推荐 / 观看历史」。
- **搜索**：全局/单源搜索、聚搜（按站点分组）、详情页快搜（分词后在其他源找同名资源）、热门搜索与输入联想、手机远程输入搜索词。
- **播放**：系统 / IJK / Exo / 阿里云播放器内核，另可调用 MX Player、Reex、Kodi 外部播放器；失败自动在 IJK 与 Exo 间切换重试。
- **播放控制**：倍速、画面比例、跳过片头片尾、续播、上/下一集（跟随正倒序）、自动下一集、横竖屏切换、触屏锁定、手势调节亮度音量进度。
- **字幕 / 音轨 / 弹幕**：内置与外挂字幕（SRT/ASS/SCC/STL/TTML）、在线字幕搜索、字幕大小延迟样式；音轨切换；弹幕显示与样式设置。
- **解析与嗅探**：Web 嗅探（系统 WebView 或 XWalkView）、JSON 解析、JSON 扩展/聚合、内置超级解析；按域名的嗅探规则、点击脚本、广告域名拦截、M3U8 广告切片过滤。
- **特殊链接**：磁力 / 迅雷 / ed2k / 种子 / FTP（迅雷 SDK）以及荐片链接直接播放。
- **直播**：TXT / M3U 直播源、多线路、超时自动换源、EPG 节目单、按节目回看、数字键换台、分组密码、可设置开机直接进入直播。
- **存储空间**：本地文件夹、WebDAV、Alist 浏览与播放，支持排序与搜索。
- **远程控制**：内置 9978 端口 HTTP 服务，手机扫码即可搜索、推送播放地址、修改配置/直播/EPG 地址、管理盒子本地文件；支持把影片推送到另一台 TVBox。
- **个性化**：7 套主题、中英文界面、首页按钮位置、壁纸更换、搜索结果展示方式。
- **数据管理**：观看历史、收藏夹、搜索历史，支持备份到存储卡与一键还原。
- **网络**：安全 DNS（DoH，可选腾讯/阿里/360/Google/AdGuard/Quad9）。
