# 点播播放器

核心代码：

- 全屏播放页：`ui/activity/PlayActivity.java`；详情页内嵌播放器：`ui/fragment/PlayFragment.java`（两者功能基本一致）
- 控制栏：`player/controller/VodController.java`、`player/controller/BaseController.java`
- 播放器内核选择：`util/PlayerHelper.java`

## 1. 播放器内核

| 编号 | 播放器 | 说明 |
| --- | --- | --- |
| 0 | 系统 | Android MediaPlayer，最新提交起支持音轨选择 |
| 1 | IJK | 默认；可切换**硬解码 / 软解码**，支持 IJK 缓存播放；参数可由配置 `ijk` 字段自定义 |
| 2 | Exo | Media3 ExoPlayer，支持 HLS / DASH / RTSP / RTMP；渲染器可选「默认 / NextLib（FFmpeg 扩展）」 |
| 3 | 阿里 | 阿里云播放器 SDK |
| 10 | MX Player | 外部播放器（已安装时才出现在列表里） |
| 11 | Reex | 外部播放器 |
| 12 | Kodi | 外部播放器，支持新版 Kodi 入口 Activity |

- 渲染方式可选 **TextureView**（默认）或 **SurfaceView**；
- 播放器优先级：站点 `playerType` → 全局设置；`设置 → 播放器设置 → 点播播放器首选` 可以选「首选配置地址」或「首选设置配置」；
- 每部影片的播放器设置（内核、缩放、倍速、片头片尾等）会跟着历史记录保存，下次打开时恢复。

## 2. 控制栏按钮

| 按钮 | 点击 | 长按 |
| --- | --- | --- |
| 上一集 / 下一集 | 切集，按当前列表顺序（倒序时跟着反过来） | — |
| 播放 / 暂停 | 切换播放状态 | — |

| 倍速 | 逐级提速：0.25 递增到 2，之后每次 +0.5 到 3，再每次 +1 到 5，然后回到 0.25；焦点在按钮上时用上 / 下键加减 | 在 1x 和 5x 之间切换 |
| 画面缩放 | 默认 → 16:9 → 4:3 → 填充 → 原始 → 裁剪，循环切换 | 横屏 / 竖屏切换 |
| 播放器 | 弹出内核选择列表 | — |
| IJK 解码 | 选择 IJK 解码方式（只在 IJK 内核下显示） | — |
| 字幕 | 打开字幕选项 | 显示 / 隐藏字幕 |
| 音轨 | 切换音轨 | — |
| 片头 | 把当前位置设为片头（只在前半段有效）；焦点在按钮上时用上 / 下键按步长调整 | 清除片头 |
| 片尾 | 把剩余时长设为片尾（只在后半段有效）；用上 / 下键按步长调整 | 清除片尾 |

- 顶部显示片名与集名、系统时间、分辨率、网速；
- 底部显示当前进度、总时长、「影片剩余」「影片结束」时间；
- 有多个解析接口时，控制栏里会出现**解析列表**，可以随时切换解析。

## 3. 遥控器操作

| 按键 | 控制栏隐藏时 | 控制栏显示时 |
| --- | --- | --- |
| 左 / 右 | 快退 / 快进，按住连续拖动 | 移动焦点 |
| 确定 / 播放暂停键 | 暂停 / 继续，暂停时自动显示控制栏 | 触发按钮 |
| 上 / 下 | 显示控制栏（上键会把焦点放到片头按钮） | 在倍速、片头、片尾按钮上调整数值 |
| 返回 | 先关闭控制栏，再退出播放 | — |

控制栏 8 秒没有操作会自动隐藏。

## 4. 触屏手势（手机 / 平板）

- **单击**：显示 / 隐藏控制栏；
- **双击**：左侧 1/3 快退 10 秒，右侧 1/3 快进 10 秒，中间暂停 / 播放；
- **长按**：临时 3 倍速快进（当前已 ≥ 3x 则保持），松手后恢复原速；
- **横向滑动**：调整进度；
- **左侧上下滑动**：调整亮度；**右侧上下滑动**：调整音量；
- **锁屏按钮**：锁定后屏蔽所有触摸操作（只在非电视设备上显示）。

## 5. 播放进度与连播

- 自动记录每一集的播放进度，再次播放时从上次位置继续；「从头播放」会清除该集进度；
- 设置了片头时开播会自动跳过片头，播到片尾时间点会自动切到下一集；
- 一集播完自动播放下一集；
- **出错自动重试**：播放失败时先在 IJK 与 Exo 之间切换内核再试；嗅探到多个候选地址时会依次尝试。

## 6. 字幕

代码：`subtitle/`、`ui/dialog/SubtitleDialog.java`、`ui/dialog/SearchSubtitleDialog.java`、`viewmodel/SubtitleViewModel.java`。

- **内置字幕**：选择视频自带的字幕轨（IJK / Exo）；
- **外挂字幕**：爬虫返回的字幕地址、本地文件选择；
- **在线搜索**：按片名在射手网（assrt.net）搜索并下载字幕，压缩包内的字幕会列出供选择；
- 支持格式：SRT、ASS/SSA、SCC、STL、TTML；
- 可以调整字幕**大小、延迟（偏移）、样式**；字幕选择结果按集缓存。

## 7. 音轨

可以列出并切换音轨，IJK、Exo 和系统播放器都支持。

## 8. 弹幕

代码：`player/danmu/Parser.java`、`ui/dialog/DanmuSettingDialog.java`，基于 DanmakuFlameMaster。

- 爬虫在播放结果里返回弹幕地址（http 或本地 file）时加载弹幕；
- 设置项：弹幕开关、大小、行数、透明度、速度（超慢 / 慢 / 适中 / 快）、颜色（默认 / 随机）；
- 画中画模式下不显示弹幕。

## 9. 后台播放与画中画

`设置 → 后台` 可选：

- **关闭**：离开页面时暂停；
- **开启**：退到后台继续播放，详情页内嵌播放器会在通知栏显示控制（上一集 / 播放暂停 / 下一集，`server/PlayService.java`）；
- **画中画**：按 Home 键时进入小窗（使用外部播放器时不进入），小窗里有上一集 / 播放暂停 / 下一集按钮。

## 10. 外部播放器

内核选 MX / Reex / Kodi 时，App 会把播放地址和请求头交给对应的外部应用播放（`player/thirdparty/`）。外部播放器不使用 HLS 预缓存。

## 11. HLS 预缓存（`设置 → 预缓存`，默认关闭）

开启后，播放 HLS 点播时会在后台把**即将播放的分片**提前下载到磁盘，减少因源站慢或网速波动造成的卡顿。

- **哪些播放会用**：经过 `playUrl` 的 HLS 点播，详情页小窗和全屏播放页都算，不管广告过滤开不开、有没有识别出广告。只处理带 `#EXT-X-ENDLIST` 的单码率媒体列表。多码率主列表、带 `#EXT-X-BYTERANGE` 的列表、没有 ENDLIST 的列表（实际是直播），以及直播、存储空间、迅雷、荐片、分段 mp4、外部播放器，都按原来的方式播放。
- **怎么做**：把 m3u8 里的分片地址改写到本地服务的分片代理 `http://127.0.0.1:<端口>/hlsseg?s=<会话>&i=<序号>`，交给播放器。分片代理按「预缓存窗口」用多个线程下载分片：从播放器最近请求的分片往后 120 秒，往前保留 30 秒；最多 3 个并发，被限流后降到 1 个；每个会话最多 300MB。命中就读磁盘，没有命中就边下边返回。
- **不解密**：分片原样下载、原样保存、原样返回，由播放器自己用 `#EXT-X-KEY` 解密。密钥和初始化段地址只补成绝对地址，播放器直接去源站取。
- **会话**：同一时间只有一个预缓存会话。m3u8 地址（取重定向后的最终地址）不变时，比如重播、出错后切内核重试，会复用已下载的分片。切集、换线路、离开播放页时清空。后台播放、画中画不算离开。
- **出错不影响播放**：源站返回的错误原样转给播放器；磁盘写入失败时，本次会话改为纯转发；m3u8 不适用时按原地址播放。
- **磁盘位置**：`<外部缓存目录>/hlscache/`。App 启动时主线程只把它改名，然后在后台删除。
- 代码：`precache/`（核心）、`util/M3u8PlayPlanner.java`（播放入口的判断）、`server/RemoteServer.java` 的 `/hlsseg` 路由。设计见 `docs/adr/0001-hls-precache-via-local-segment-proxy.md`。
