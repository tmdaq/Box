# 存储空间（本地 / 网盘）

在首页「文件」入口进入。核心代码：`ui/activity/DriveActivity.java`、`viewmodel/drive/`、`cache/StorageDrive*.java`。

## 1. 支持的存储类型

| 类型 | 添加时填写 | 实现 |
| --- | --- | --- |
| 本地 | 用文件选择器选一个本地文件夹（同一文件夹不能重复添加） | `LocalDriveViewModel` |
| WebDAV | 空间名称、WebDAV 地址、初始路径、用户名、密码 | `WebDAVDriveViewModel`（sardine-android） |
| Alist | 空间名称、Alist 地址、初始路径、密码 | `AlistDriveViewModel`（调用 `/api/fs/list`） |

添加的空间保存在本地数据库里，下次打开直接显示在空间列表中。

## 2. 浏览与操作

- 逐级进入目录，返回键回到上一级；「主页」按钮回到空间列表；
- **排序**：按名字升序 / 降序、按修改时间升序 / 降序，排序方式会保存；
- **删除空间**：进入删除模式后选中空间即可移除；
- 本地存储需要存储权限，第一次使用时会申请。

## 3. 播放

- 选中视频文件后，以 `tvbox-drive://` 地址交给播放器播放；
- WebDAV 播放时自动带上 `authorization: Basic ...` 认证请求头；
- 不支持的文件类型会提示「Media Unsupported」；
- 播放进度以文件地址为单位单独记录，可以续播；
- 播放器的缩放、倍速、片头片尾等功能都可以用。

## 4. 与远程控制配合

在手机浏览器打开远程控制页面的「本地文件」模块，可以向盒子存储卡上传文件（zip 包会自动解压）、新建或删除文件夹、删除文件，详见 [09-远程控制与推送](09-远程控制与推送.md)。
