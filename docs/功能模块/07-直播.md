# 直播

核心代码：`ui/activity/LivePlayActivity.java`、`util/live/TxtSubscribe.java`、`util/EpgUtil.java`、`api/ApiConfig.java`（`lives` 解析部分）。

## 1. 直播源

### 1.1 来源与优先级

- 配置地址里的 `lives` 字段；
- `设置 → 配置地址` 中单独填写的「直播地址」，**优先级高于**配置中的地址；
- 直播地址会自动加入「直播历史列表」，可以在直播设置菜单或配置对话框里切换。

### 1.2 `lives` 支持的写法

| 写法 | 说明 |
| --- | --- |
| `proxy://do=live&type=txt&ext=地址` | 旧式代理写法，`ext` 可以是 http / `clan://` 地址或 Base64 编码 |
| `{"type":"0","url":"http://...","epg":"...","playerType":1}` | FongMi 风格写法，可以带 EPG 地址和直播专用播放器 |
| `[{"group":"分组","channels":[{"name":"频道","urls":["..."]}]}]` | 直接内嵌的频道 JSON |

最终都通过本地代理 `http://127.0.0.1:9978/proxy?do=live&type=txt&ext=...` 下载并解析频道列表。

### 1.3 频道列表格式

`TxtSubscribe` 支持两种格式：

**TXT 格式**

```
央视频道,#genre#
CCTV-1,http://a.m3u8#http://b.m3u8
CCTV-1,rtmp://c
卫视频道,#genre#
湖南卫视,http://d.m3u8
```

- `分组名,#genre#` 开始一个分组；没有分组的频道归到「未分组」；
- 一行里可以用 `#` 分隔多个地址；同名频道出现多次时地址会合并成**多条线路**；
- 支持 http / rtsp / rtmp 地址。

**M3U 格式**

以 `#EXTM3U` 开头，用 `#EXTINF` 的 `group-title` 分组。

### 1.4 分组密码

分组名写成 `分组名_密码` 时，进入该分组前要输入密码（`LivePasswordDialog`）。直播设置中的「关闭密码」可以跳过密码。

### 1.5 请求头

- 默认请求头 `User-Agent: Lavf/59.27.100`；
- 配置里的 `livePlayHeaders` 可以按地址关键字（`flag`）给直播地址指定请求头。

## 2. 遥控器操作

| 按键 | 正常直播 | 回看中 |
| --- | --- | --- |
| 上 / 下 | 上一个 / 下一个频道（可以在设置里反转） | 同左 |
| 左 | 打开设置菜单 | 显示节目信息 / 进度条 |
| 右 | 切换到下一条线路 | 显示节目信息 / 进度条 |
| 确定 / 播放键 | 打开频道列表 | 同左 |
| 菜单键 | 打开设置菜单 | 同左 |
| 数字键 | 输入频道号直接换台 | 同左 |
| 返回 | 连按两次退出直播 | — |

- 频道列表左边是分组，右边是频道，「跨选分类」打开后上下换台可以跨分组；
- 记住上次观看的频道，下次进入时自动播放。

## 3. 设置菜单

| 分组 | 选项 |
| --- | --- |
| 线路选择 | 当前频道的所有线路（屏幕上显示「线路 x/n」） |
| 画面比例 | 默认 / 16:9 / 4:3 / 填充 / 原始 / 裁剪 |
| 播放解码 | 系统 / ijk硬解 / ijk软解 / exo |
| 超时换源 | 关 / 5s / 10s / 15s / 20s / 25s / 30s：在设定时间内没加载出来就自动换下一条线路 |
| 偏好设置 | 显示时间、显示网速、换台反转、跨选分类、关闭密码 |
| 直播地址 | 列表历史：切换历史直播地址 |
| 退出直播 | 确定退出 |

## 4. EPG 节目单

- EPG 地址来源：配置 `lives[].epg` 或设置里填的 EPG 地址（设置里的优先）；没有配置时使用默认接口 `https://epg.112114.xyz/`；
- 地址模板：
  - 包含 `{name}` 和 `{date}` 时替换成频道名和日期；
  - 否则自动拼成 `地址?ch=频道名&date=yyyy-MM-dd`；
- 接口返回 `epg_data`（`title`、`start`、`end`）；
- 频道信息栏显示**当前节目和下一个节目**；
- 节目单可以按日期查看（昨天 / 今天 / 明天 / 后天等）；
- `assets/epg_data.json` 内置频道别名到 EPG 标识的映射，以及频道台标地址，所以「CCTV1」「CCTV-1综合」这类不同写法能对到同一个节目单。

## 5. 回看（时移）

- 支持回看的频道（地址中带 `PLTV/8888`）可以在节目单中选择已经播出的节目；
- 回看时在地址后追加 `?playseek=开始时间-结束时间` 播放；
- 回看状态下会显示进度条，可以拖动。

## 6. 其他

- 可以显示网速（MB/s）、系统时间、分辨率；
- `设置 → 启动时进直播` 打开后，App 启动直接进入直播；
- 配置 `lives[].playerType` 可以给直播单独指定播放器。
