# 远程控制与推送

TVBox 启动时会在本机开一个 HTTP 服务，让手机 / 电脑通过浏览器遥控盒子；它也是爬虫代理、M3U8 去广告和直播源加载的基础。

核心代码：`server/ControlManager.java`、`server/RemoteServer.java`（NanoHTTPD）、`server/InputRequestProcess.java`、`server/WebController.kt`（AndServer），网页资源在 `res/raw/index.html`、`script.js`、`style.css`。

## 1. 服务地址

- 默认端口 **9978**，被占用时依次尝试下一个端口（最大到 9999）；
- 局域网地址：`http://<盒子IP>:9978/`，本机地址：`http://127.0.0.1:9978/`；
- 推送页、搜索页、配置地址对话框里都会显示这个地址的**二维码**，手机扫码即可打开。

## 2. 遥控网页

浏览器打开服务地址后可以使用以下模块：

| 模块 | 功能 |
| --- | --- |
| TVBox · 搜索 | 输入关键词，盒子自动打开搜索页并开始搜索 |
| TVBox · 推送 | 推送播放地址，盒子会用 `push_agent` 站点打开详情页播放 |
| TVBox · 接口 | 远程填写配置地址、直播地址、EPG 地址（盒子上的配置地址对话框打开时自动填入） |
| 本地文件 | 浏览盒子存储卡文件；上传文件（zip 自动解压）、新建文件夹、删除文件夹 / 文件 |

## 3. 推送播放

### 3.1 推送页

首页「推送」入口（`ui/activity/PushActivity.java`）：

- 显示遥控二维码和地址；
- **推送剪贴板内容**：把盒子剪贴板里的链接当作推送地址直接打开。

### 3.2 推送到另一台 TVBox

详情页的「推送」按钮：填写对方 TVBox 的 IP 和端口（会记住），把当前影片的 `id` + `sourceKey` 发给对方的 `/action?do=mirror`，对方直接打开同一部影片的详情页。

### 3.3 推送链接格式

- 配置里需要有 key 为 `push_agent` 的站点；
- 链接 `push://地址`（地址做 URL 编码）或 `push://b64:Base64地址` 会被识别成推送链接，交给 `push_agent` 处理；
- 接口 `GET /api/updateUrl?url=...` 也可以推送地址。

## 4. HTTP 接口一览

| 路径 | 方法 | 说明 |
| --- | --- | --- |
| `/` | GET | 遥控网页 |
| `/action?do=search&word=` | POST | 远程搜索 |
| `/action?do=api&url=` / `live` / `epg` / `proxys` | POST | 远程填写配置 / 直播 / EPG / 代理地址 |
| `/action?do=push&url=` | POST | 推送播放地址 |
| `/action?do=mirror&id=&sourceKey=` | POST | 打开指定影片的详情页（设备间推送） |
| `/api/updateUrl?url=` | GET | 推送播放地址 |
| `/api/remote/version`、`/index.html` | GET | 探活 |
| `/media` | GET | 正在播放的影片名和集名（JSON） |
| `/proxy?do=...` | GET | 爬虫本地代理（Jar / JS / Python 的 `proxyLocal`），也用于直播源加载 `do=live` |
| `/proxy?go=...` | GET | 通用转发代理 |
| `/m3u8` | GET | 播放器使用的 M3U8 内容：去广告后的结果；开启预缓存时，分片地址指向 `/hlsseg` |
| `/hlsseg?s=<会话>&i=<序号>` | GET | HLS 预缓存的分片代理，**只接受本机（127.0.0.1）请求**，其他来源返回 403。源站错误原样返回，会话失效时返回 410，响应不做 gzip |
| `/dash/...` | GET | 爬虫提供的 DASH（mpd）数据 |
| `/dns-query?name=` | GET | DoH 转发 |
| `/file/<路径>` | GET | 读取存储卡文件或列出目录 |
| `/upload`、`/newFolder`、`/delFolder`、`/delFile` | POST | 存储卡文件管理 |

## 5. 系统广播接口

其他应用（比如语音助手、桌面）可以用广播控制 TVBox：

| Action | Extras | 效果 |
| --- | --- | --- |
| `android.content.movie.search.Action` | `title` | 打开搜索页并搜索 |
| `android.content.movie.detail.Action` | `id`、`sourceKey` | 打开影片详情页 |
| `android.content.movie.custom.web.Action` | `action`（刷新解析 / 刷新直播等） | 通知 App 刷新对应数据 |
