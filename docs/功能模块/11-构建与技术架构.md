# 构建与技术架构

## 1. 工程模块

| 模块 | 说明 |
| --- | --- |
| `:app` | 主应用 |
| `:quickjs` | QuickJS 引擎（自带 jniLibs），运行 JS 爬虫 |
| `:pyramid` | Python 运行环境（Chaquopy），只有 `python` 变体会依赖它 |
| `xwalk/` | Crosswalk（XWalkView）运行组件安装包，按 CPU 架构分开 |
| `app/libs/` | `thunder.jar`（迅雷 SDK）、`xwalk_shared_library`、`lib-decoder-ffmpeg`、`dec` 等本地依赖 |

工具链：Gradle 7.5、Android Gradle Plugin 7.4.2、Kotlin 1.9.25，`compileSdk 34`、`targetSdk 28`、`minSdk 21`，Java 8。

## 2. 构建变体

`productFlavors` 有三个维度，组合出多个 APK：

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| `abi` | `armeabi`（armeabi-v7a）/ `arm64`（arm64-v8a） | CPU 架构 |
| `brand` | `generic`（通用）/ `hisense`（海信，包名 `com.github.hisense.osc.tk`） | 品牌渠道 |
| `mode` | `normal`（文件名里显示为 `java`）/ `python` | 是否内置 Python 爬虫支持 |

- 输出文件名：`TVBox_<buildType>-<abi>-<brand>-<mode>.apk`，例如 `TVBox_release-arm64-generic-java.apk`；
- 版本号 `versionName` 为 `1.0.<yyyyMMdd_HHmm>`（北京时间构建时间）；
- `release` 开启混淆，`python` 变体额外使用 `proguard-python.pro`；
- `normal` 和 `python` 变体分别在 `app/src/normal`、`app/src/python` 提供不同的 `pyLoader` 实现。

## 4. 源码结构（`app/src/main/java/com/github/tvbox/osc/`）

| 目录 | 内容 |
| --- | --- |
| `api/` | `ApiConfig`：配置加载、站点 / 解析 / 直播 / 规则解析、爬虫分发 |
| `base/` | `App`（初始化与默认设置）、`BaseActivity`、`BaseLazyFragment` |
| `bean/` | 数据模型：站点、影片、选集、直播频道、EPG、字幕等 |
| `cache/`、`data/` | Room 实体与 DAO：历史、收藏、搜索历史、存储空间、通用缓存 |
| `ui/activity/` | 首页、详情、播放、直播、搜索、聚搜、历史、收藏、存储、推送、应用、设置 |
| `ui/fragment/` | 首页推荐页、分类列表页、设置页、内嵌播放页 |
| `ui/dialog/` | 各类对话框（配置、筛选、字幕、弹幕、备份、推送等） |
| `player/` | 播放器封装、控制栏、外部播放器、弹幕解析 |
| `server/` | 本地 HTTP 服务与遥控 |
| `subtitle/` | 字幕解析与显示 |
| `viewmodel/` | 站点数据加载（`SourceViewModel`）、字幕搜索、存储空间 |
| `util/` | 工具类：解析规则、去广告、M3U8、DoH、EPG、迅雷、JS 运行时桥接等 |
| `receiver/` | 系统广播接收器 |

其他包：

- `com/github/catvod/crawler/`：爬虫基类 `Spider` 与 `JarLoader` / `JsLoader`；
- `xyz/doikki/videoplayer/`：DKPlayer 内核适配（IJK / Exo / 阿里 / 系统）；
- `tv/danmaku/ijk/`：IjkPlayer Java 层；
- `com/google/androidx/media3/`：ExoPlayer 定制扩展（OkHttp 数据源、TS 解析）。

## 5. 主要流程

```
启动 App
  └─ HomeActivity
       ├─ ApiConfig.loadConfig()      加载 / 解密 / 缓存配置
       ├─ ApiConfig.loadJar()         加载全局 spider Jar
       ├─ ControlManager 启动 9978 服务
       └─ SourceViewModel             获取首页分类与推荐
            └─ 点影片 → DetailActivity（详情 + PlayFragment 预览）
                 └─ SourceViewModel.getPlay()  爬虫 playerContent
                      ├─ 直接播放
                      ├─ 解析：JSON / Web 嗅探 / 聚合 / 超级解析
                      ├─ 磁力 / 迅雷 / 荐片 → Thunder SDK
                      └─ M3U8 去广告 → 127.0.0.1:9978/m3u8 → 播放器
```
