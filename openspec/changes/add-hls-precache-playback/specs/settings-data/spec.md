## MODIFIED Requirements

### Requirement: 播放器设置项
「播放器」组 SHALL 提供以下设置项，未修改时 MUST 使用加粗标注的默认值；外部播放器（如 MX、Reex、Kodi）MUST 先安装才能使用：

| 设置项 | 可选值（默认值加粗） | 说明 |
| --- | --- | --- |
| 窗口预览 | **开启** / 关闭 | 详情页小窗播放 |
| 画面缩放 | **默认** / 16:9 / 4:3 / 填充 / 原始 / 裁剪 | 默认画面比例 |
| 后台 | **关闭** / 开启 / 画中画 | 离开播放页后的行为 |
| 播放器 | 系统 / **IJK** / Exo / 阿里 / MX / Reex / Kodi | 默认播放内核 |
| 播放器设置 | 通用：点播播放器首选（首选配置地址 / 首选设置配置）；EXO：渲染器（默认 / NextLib）；IJK：解码模式（软解码 / **硬解码**）、缓存 | 内核的细分参数 |
| 广告过滤 | **开启** / 关闭 | M3U8 去广告 |
| 预缓存 | 开启 / **关闭** | HLS 点播时在后台把即将播放的分片提前下载到磁盘，见 `vod-player`「预缓存的作用范围」；和「播放器设置」里的 IJK「缓存」不是同一个功能 |

「预缓存」和「广告过滤」一样，点一下就在开启和关闭之间切换，设置项上直接显示当前状态；用遥控器方向键 MUST 能移动到该设置项。

#### Scenario: 默认值
- **WHEN** 用户从未修改过播放器设置
- **THEN** 窗口预览开启，画面缩放为默认，后台为关闭，播放器为 IJK，IJK 解码模式为硬解码，广告过滤开启，预缓存关闭

#### Scenario: 关闭窗口预览
- **WHEN** 用户将「窗口预览」设为关闭
- **THEN** 详情页不再以小窗播放

#### Scenario: 选择外部播放器
- **WHEN** 用户选择 MX、Reex 或 Kodi 作为播放器
- **THEN** 只有在该外部播放器已安装时才能使用它播放

#### Scenario: 关闭广告过滤
- **WHEN** 用户将「广告过滤」设为关闭
- **THEN** 系统不再对 M3U8 去广告

#### Scenario: 切换预缓存
- **WHEN** 用户在设置页用遥控器方向键移动到「预缓存」并按确认键，或者用触屏点击它
- **THEN** 「预缓存」在开启和关闭之间切换，设置项上显示的状态随之更新
- **AND** 退出设置页再进入，或者重启 App 后，显示的状态保持不变

#### Scenario: 老用户升级后预缓存关闭
- **WHEN** 用户从没有「预缓存」设置项的旧版本升级
- **THEN** 「预缓存」显示为关闭，播放行为和升级前一致
