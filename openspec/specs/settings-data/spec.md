# 设置与数据管理

## Purpose
提供首页、播放器、系统三组设置项，并管理观看历史、收藏夹、数据备份与还原、重置和缓存清理，让用户自定义 App 行为并保存、迁移或清除自己的数据。设置项持久化保存，历史、收藏、搜索历史、存储空间等数据保存在本地数据库中。

## Requirements

### Requirement: 设置与数据持久化
系统 SHALL 将所有设置项持久化保存（Hawk 存储于 SharedPreferences），并 MUST 将观看历史、收藏、搜索历史、存储空间等数据保存在本地 Room 数据库中，重启 App 后仍然保留。

#### Scenario: 重启后设置保留
- **WHEN** 用户修改任一设置项后重启 App
- **THEN** 该设置项保持修改后的值

#### Scenario: 重启后数据保留
- **WHEN** 用户产生了观看历史、收藏或搜索历史后重启 App
- **THEN** 这些数据仍然存在

### Requirement: 设置页分组
设置页 SHALL 分成「首页」「播放器」「系统」三组设置项。

#### Scenario: 打开设置页
- **WHEN** 用户打开设置页
- **THEN** 设置项按「首页」「播放器」「系统」三组展示

### Requirement: 首页设置项
「首页」组 SHALL 提供以下设置项，未修改时 MUST 使用加粗标注的默认值：

| 设置项 | 可选值（默认值加粗） | 说明 |
| --- | --- | --- |
| 配置地址 | — | 填写配置 / 直播 / EPG / 代理地址 |
| 配置历史 | — | 从历史配置中切换 |
| 数据源 | 配置中未隐藏的站点 | 首页使用的站点 |
| 数据源显示 | **开启** / 关闭 | 首页顶部显示站点名称 |
| 按钮位置 | 搜索、设置按钮各自可选上方 / 下方（搜索默认**下方**，设置默认**上方**） | 首页快捷按钮的位置 |
| 推荐 | 豆瓣热播 / **站点推荐** / 观看历史 | 首页第一页内容 |
| 历史条数 | 20 / 40 / 60 / 80 / **100** | 保留多少条观看历史 |
| 启动时进直播 | 开启 / **关闭** | 启动后直接进入直播 |

#### Scenario: 默认值
- **WHEN** 用户从未修改过首页设置
- **THEN** 数据源显示为开启，搜索按钮在下方、设置按钮在上方，推荐为站点推荐，历史条数为 100，启动时进直播为关闭

#### Scenario: 从配置历史切换
- **WHEN** 用户在「配置历史」中选择一条历史配置
- **THEN** App 切换到该配置

#### Scenario: 选择数据源
- **WHEN** 用户打开「数据源」设置
- **THEN** 可选列表只包含配置中未隐藏的站点
- **AND** 选中的站点成为首页使用的站点

#### Scenario: 关闭数据源显示
- **WHEN** 用户将「数据源显示」设为关闭
- **THEN** 首页顶部不再显示站点名称

#### Scenario: 启动时进直播
- **WHEN** 「启动时进直播」为开启且用户启动 App
- **THEN** App 启动后直接进入直播

### Requirement: 播放器设置项
「播放器」组 SHALL 提供以下设置项，未修改时 MUST 使用加粗标注的默认值；外部播放器（如 MX、Reex、Kodi）MUST 先安装才能使用：

| 设置项 | 可选值（默认值加粗） | 说明 |
| --- | --- | --- |
| 窗口预览 | **开启** / 关闭 | 详情页小窗播放 |
| 画面缩放 | **默认** / 16:9 / 4:3 / 填充 / 原始 / 裁剪 | 默认画面比例 |
| 后台 | **关闭** / 开启 / 画中画 | 离开播放页后的行为 |
| 播放器 | 系统 / **IJK** / Exo / 阿里 / MX / Reex / Kodi | 默认播放内核 |
| 播放器设置 | 通用：点播播放器首选（首选配置地址 / 首选设置配置）；EXO：渲染器（默认 / NextLib）；IJK：解码模式（软解码 / **硬解码**）、缓存 | 内核的细分参数 |
| 广告过滤 | **开启** / 关闭 | M3U8 去广告 |
| 预缓存 | 开启 / **关闭** | HLS 点播时在后台把即将播放的分片提前下载到磁盘，见 `vod-player`「预缓存的作用范围」；和「播放器设置」里的 IJK「缓存」不是同一个功能 |

「预缓存」和「广告过滤」一样，点一下就在开启和关闭之间切换，设置项上直接显示当前状态；用遥控器方向键 MUST 能移动到该设置项。

#### Scenario: 默认值
- **WHEN** 用户从未修改过播放器设置
- **THEN** 窗口预览开启，画面缩放为默认，后台为关闭，播放器为 IJK，IJK 解码模式为硬解码，广告过滤开启，预缓存关闭

#### Scenario: 关闭窗口预览
- **WHEN** 用户将「窗口预览」设为关闭
- **THEN** 详情页不再以小窗播放

#### Scenario: 选择外部播放器
- **WHEN** 用户选择 MX、Reex 或 Kodi 作为播放器
- **THEN** 只有在该外部播放器已安装时才能使用它播放

#### Scenario: 关闭广告过滤
- **WHEN** 用户将「广告过滤」设为关闭
- **THEN** 系统不再对 M3U8 去广告

#### Scenario: 切换预缓存
- **WHEN** 用户在设置页用遥控器方向键移动到「预缓存」并按确认键，或者用触屏点击它
- **THEN** 「预缓存」在开启和关闭之间切换，设置项上显示的状态随之更新
- **AND** 退出设置页再进入，或者重启 App 后，显示的状态保持不变

#### Scenario: 老用户升级后预缓存关闭
- **WHEN** 用户从没有「预缓存」设置项的旧版本升级
- **THEN** 「预缓存」显示为关闭，播放行为和升级前一致

### Requirement: 系统设置项
「系统」组 SHALL 提供以下设置项，未修改时 MUST 使用加粗标注的默认值：

| 设置项 | 可选值（默认值加粗） | 说明 |
| --- | --- | --- |
| 语言 | **中文** / 英文 | 界面语言 |
| 主题 | **奈飞** / 哆啦 / 百事 / 鸣人 / 小黄 / 八神 / 樱花 | 7 套主题色 |
| 换张壁纸 / 重置壁纸 | — | 用配置里的 `wallpaper` 换背景 / 恢复默认 |
| 渲染方式 | **TextureView** / SurfaceView | 视频渲染视图 |
| 搜索展示 | 文字列表 / **缩略图** | 搜索结果样式 |
| 嗅探Webview | **系统自带** / XWalkView | 解析嗅探用的内核 |
| 安全DNS | **关闭** / 腾讯 / 阿里 / 360 / Google / AdGuard / Quad9 | DoH |
| 聚搜 | 开启 / **关闭** | 搜索结果使用按站点分组的聚搜页 |
| 数据备份还原 | — | 打开数据备份与还原 |
| 重置 | — | 清除所有数据并重启 |
| 关于 | — | 声明与项目地址 |

#### Scenario: 默认值
- **WHEN** 用户从未修改过系统设置
- **THEN** 语言为中文，主题为奈飞，渲染方式为 TextureView，搜索展示为缩略图，嗅探 Webview 为系统自带，安全 DNS 为关闭，聚搜为关闭

#### Scenario: 换张壁纸
- **WHEN** 用户点击「换张壁纸」
- **THEN** 系统使用配置里的 `wallpaper` 更换背景

#### Scenario: 重置壁纸
- **WHEN** 用户点击「重置壁纸」
- **THEN** 背景恢复为默认壁纸

#### Scenario: 开启聚搜
- **WHEN** 用户将「聚搜」设为开启后进行搜索
- **THEN** 搜索结果使用按站点分组的聚搜页展示

#### Scenario: 查看关于
- **WHEN** 用户点击「关于」
- **THEN** 显示声明与项目地址

### Requirement: 隐藏的调试模式
在设置页用遥控器快速连按数字键 0 四次（每次间隔不超过 200ms）时，系统 SHALL 显示「调试模式」开关。调试模式打开后，解析嗅探的 WebView MUST 显示在前台并加载图片，方便排查解析问题。

#### Scenario: 唤出调试模式开关
- **WHEN** 用户在设置页连续按数字键 0 四次，且每次间隔不超过 200ms
- **THEN** 设置页出现「调试模式」开关

#### Scenario: 按键间隔过长
- **WHEN** 用户在设置页按数字键 0 时某次间隔超过 200ms
- **THEN** 不会因此唤出「调试模式」开关

#### Scenario: 开启调试模式
- **WHEN** 用户打开「调试模式」后触发解析嗅探
- **THEN** 嗅探用的 WebView 显示在前台并加载图片

### Requirement: 观看历史
系统 SHALL 自动记录观看历史，包括影片、线路、集数、播放进度、排序状态和播放器配置；保留条数 MUST 由「历史条数」设置控制。历史页 SHALL 支持删除单条（删除模式）和清空全部（需要确认）；首页推荐选择「观看历史」时也 SHALL 支持长按删除。

#### Scenario: 自动记录
- **WHEN** 用户播放某部影片
- **THEN** 系统记录该影片的线路、集数、播放进度、排序状态和播放器配置

#### Scenario: 超出保留条数
- **WHEN** 观看历史条数超过「历史条数」设置值
- **THEN** 系统只保留设置值数量的历史记录

#### Scenario: 删除单条历史
- **WHEN** 用户在历史页进入删除模式并选择一条记录
- **THEN** 该条历史被删除

#### Scenario: 清空全部历史
- **WHEN** 用户在历史页选择清空全部
- **THEN** 系统先要求确认，确认后清空所有观看历史

#### Scenario: 首页长按删除历史
- **WHEN** 首页推荐设置为「观看历史」，用户在首页长按某条历史
- **THEN** 该条历史被删除

### Requirement: 收藏夹
用户 SHALL 能在详情页通过「★ 收藏」添加或取消收藏；收藏夹 MUST 支持删除单条和清空全部。

#### Scenario: 添加收藏
- **WHEN** 用户在未收藏影片的详情页点击「★ 收藏」
- **THEN** 该影片加入收藏夹

#### Scenario: 取消收藏
- **WHEN** 用户在已收藏影片的详情页点击「★ 收藏」
- **THEN** 该影片从收藏夹移除

#### Scenario: 管理收藏夹
- **WHEN** 用户在收藏夹中删除单条或选择清空全部
- **THEN** 对应收藏被删除或全部收藏被清空

### Requirement: 数据备份
「立即备份」SHALL 在存储卡的 `tvbox_backup/<yyyy-MM-dd-HHmmss>/` 目录下保存备份，备份内容 MUST 包括 `sqlite`（Room 数据库：历史、收藏、存储空间等）和 `hawk`（全部设置项，包括加密密钥）。备份功能 MUST 具备存储权限才能使用。

#### Scenario: 立即备份
- **WHEN** 用户已授予存储权限并点击「立即备份」
- **THEN** 存储卡上生成 `tvbox_backup/<yyyy-MM-dd-HHmmss>/` 目录
- **AND** 目录下包含 `sqlite` 和 `hawk` 两份备份数据

#### Scenario: 缺少存储权限
- **WHEN** App 未获得存储权限
- **THEN** 无法进行备份与还原，需要先授予存储权限

### Requirement: 数据还原与备份管理
备份列表 SHALL 列出已有备份；用户点选某个备份时系统 MUST 用它还原数据，还原后 App 自动重启。用户 SHALL 能删除旧备份。

#### Scenario: 还原备份
- **WHEN** 用户在备份列表中点选某个备份
- **THEN** 系统用该备份还原数据库和设置项
- **AND** App 自动重启

#### Scenario: 删除旧备份
- **WHEN** 用户在备份列表中删除某个旧备份
- **THEN** 该备份从存储卡上移除并不再出现在列表中

### Requirement: 重置
在「设置 → 重置」确认后，系统 MUST 清除 App 的公共和私有数据（配置、缓存、数据库等），然后自动重启。

#### Scenario: 确认重置
- **WHEN** 用户点击「设置 → 重置」并确认
- **THEN** App 的配置、缓存、数据库等公共和私有数据被清除
- **AND** App 自动重启

### Requirement: 缓存清理
首页点击 App 名称时，系统 SHALL 清空缓存目录，并删除当前站点的 Jar 缓存后重新加载。Jar 缓存长时间（超过一周）未手动清理时，系统 MUST 自动清理并重新获取，带 md5 校验的 Jar 除外。

#### Scenario: 点击 App 名称清理缓存
- **WHEN** 用户在首页点击 App 名称
- **THEN** 缓存目录被清空
- **AND** 当前站点的 Jar 缓存被删除并重新加载

#### Scenario: Jar 缓存自动过期
- **WHEN** 不带 md5 校验的 Jar 缓存超过一周未手动清理
- **THEN** 系统不再使用该缓存，而是重新下载 Jar

#### Scenario: 带 md5 校验的 Jar
- **WHEN** Jar 地址带有 md5 校验且本地缓存校验通过
- **THEN** 系统继续使用该缓存，不做自动清理
