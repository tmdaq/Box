# 点播播放器

## Purpose
点播播放器负责播放影视点播内容，包括全屏播放页与详情页内嵌播放器（两者功能基本一致），提供多播放器内核选择、控制栏、遥控器与触屏操作、进度记忆与连播、字幕、音轨、弹幕、后台播放与画中画以及外部播放器调用能力。

## Requirements

### Requirement: 播放器内核
系统 SHALL 提供以下播放器内核供选择，默认内核 MUST 为 IJK：

| 编号 | 播放器 | 说明 |
| --- | --- | --- |
| 0 | 系统 | Android MediaPlayer，支持音轨选择 |
| 1 | IJK | 默认；可切换硬解码 / 软解码，支持 IJK 缓存播放；参数可由配置 `ijk` 字段自定义 |
| 2 | Exo | Media3 ExoPlayer，支持 HLS / DASH / RTSP / RTMP；渲染器可选「默认 / NextLib（FFmpeg 扩展）」 |
| 3 | 阿里 | 阿里云播放器 SDK |
| 10 | MX Player | 外部播放器，已安装时才出现在列表里 |
| 11 | Reex | 外部播放器 |
| 12 | Kodi | 外部播放器，支持新版 Kodi 入口 Activity |

#### Scenario: 未做任何选择时使用默认内核
- **WHEN** 站点与全局设置都未指定播放器内核
- **THEN** 系统使用 IJK 内核播放

#### Scenario: IJK 解码方式与参数
- **WHEN** 使用 IJK 内核
- **THEN** 用户可以在硬解码与软解码之间切换，并可使用 IJK 缓存播放
- **AND** 配置中提供 `ijk` 字段时，IJK 参数按该字段自定义

#### Scenario: Exo 渲染器选择
- **WHEN** 使用 Exo 内核
- **THEN** 用户可以选择「默认」或「NextLib（FFmpeg 扩展）」渲染器

#### Scenario: MX Player 未安装
- **WHEN** 设备未安装 MX Player
- **THEN** 内核选择列表中不出现 MX Player

### Requirement: 渲染方式
系统 SHALL 支持 TextureView 与 SurfaceView 两种渲染方式，默认 MUST 为 TextureView。

#### Scenario: 默认渲染方式
- **WHEN** 用户未修改渲染方式
- **THEN** 系统使用 TextureView 渲染画面

#### Scenario: 切换为 SurfaceView
- **WHEN** 用户把渲染方式设为 SurfaceView
- **THEN** 系统使用 SurfaceView 渲染画面

### Requirement: 播放器优先级
影片历史里没有保存过播放器选择时，系统 SHALL 按「站点 `playerType` → 全局设置」的优先级决定使用的播放器；`设置 → 播放器设置 → 点播播放器首选` MUST 允许选择「首选配置地址」或「首选设置配置」。

#### Scenario: 首选配置地址
- **WHEN** 点播播放器首选为「首选配置地址」且站点配置了 `playerType`
- **THEN** 系统使用站点 `playerType` 指定的播放器

#### Scenario: 首选设置配置
- **WHEN** 点播播放器首选为「首选设置配置」
- **THEN** 系统使用全局设置中的播放器

### Requirement: 每部影片的播放器设置随历史保存
系统 SHALL 把每部影片的播放器设置（内核、缩放、倍速、片头片尾等）随历史记录保存，并 MUST 在下次打开该影片时恢复。

#### Scenario: 再次打开影片恢复设置
- **WHEN** 用户对某部影片调整了内核、缩放、倍速或片头片尾后退出，之后再次打开该影片
- **THEN** 系统恢复上次保存的内核、缩放、倍速与片头片尾设置

### Requirement: 切集按钮
控制栏 SHALL 提供上一集 / 下一集按钮，切集 MUST 按当前列表顺序进行，列表倒序时方向跟着反过来。

#### Scenario: 正序列表点击下一集
- **WHEN** 选集列表为正序，用户点击下一集
- **THEN** 系统播放当前列表顺序中的下一条

#### Scenario: 倒序列表点击下一集
- **WHEN** 选集列表为倒序，用户点击下一集
- **THEN** 系统按倒序后的列表顺序播放下一条

### Requirement: 播放暂停与重播按钮
控制栏 SHALL 提供播放 / 暂停按钮和重播按钮；重播按钮点击 MUST 从头重新播放，长按 MUST 从当前位置重新加载。

#### Scenario: 点击播放 / 暂停
- **WHEN** 用户点击播放 / 暂停按钮
- **THEN** 系统切换播放与暂停状态

#### Scenario: 点击重播
- **WHEN** 用户点击重播按钮
- **THEN** 系统从头重新播放当前集

#### Scenario: 长按重播刷新
- **WHEN** 用户长按重播按钮
- **THEN** 系统从当前位置重新加载（刷新）播放

### Requirement: 倍速按钮
控制栏 SHALL 提供倍速按钮。点击时 MUST 逐级提速：从 0.25 起每次 +0.25 到 2，之后每次 +0.5 到 3，再每次 +1 到 5，到 5 后再点击回到 0.25。焦点在倍速按钮上时，上 / 下键用于加减倍速；长按在 1x 与 5x 之间切换。

#### Scenario: 低速区逐级提速
- **WHEN** 当前倍速为 1.75，用户点击倍速按钮
- **THEN** 倍速变为 2

#### Scenario: 中速区提速
- **WHEN** 当前倍速为 2，用户点击倍速按钮
- **THEN** 倍速变为 2.5

#### Scenario: 高速区提速
- **WHEN** 当前倍速为 3，用户点击倍速按钮
- **THEN** 倍速变为 4

#### Scenario: 最高倍速后循环
- **WHEN** 当前倍速为 5，用户点击倍速按钮
- **THEN** 倍速回到 0.25

#### Scenario: 遥控器上下键调整倍速
- **WHEN** 焦点在倍速按钮上，用户按上键或下键
- **THEN** 倍速相应增加或减少一级

#### Scenario: 长按切换 1x 与 5x
- **WHEN** 用户长按倍速按钮
- **THEN** 倍速在 1x 与 5x 之间切换

### Requirement: 画面缩放按钮
控制栏 SHALL 提供画面缩放按钮，点击时 MUST 按「默认 → 16:9 → 4:3 → 填充 → 原始 → 裁剪」循环切换；长按切换横屏 / 竖屏。

#### Scenario: 点击切换缩放
- **WHEN** 当前缩放为「默认」，用户点击画面缩放按钮
- **THEN** 缩放变为 16:9

#### Scenario: 缩放循环
- **WHEN** 当前缩放为「裁剪」，用户点击画面缩放按钮
- **THEN** 缩放回到「默认」

#### Scenario: 长按切换横竖屏
- **WHEN** 用户长按画面缩放按钮
- **THEN** 画面在横屏与竖屏之间切换

### Requirement: 播放器与 IJK 解码按钮
控制栏 SHALL 提供播放器按钮，点击 MUST 弹出内核选择列表；IJK 解码按钮 MUST 只在 IJK 内核下显示，点击用于选择 IJK 解码方式。

#### Scenario: 切换内核
- **WHEN** 用户点击播放器按钮
- **THEN** 系统弹出内核选择列表

#### Scenario: IJK 内核下显示解码按钮
- **WHEN** 当前内核为 IJK
- **THEN** 控制栏显示 IJK 解码按钮，点击可选择解码方式

#### Scenario: 非 IJK 内核隐藏解码按钮
- **WHEN** 当前内核不是 IJK
- **THEN** 控制栏不显示 IJK 解码按钮

### Requirement: 字幕与音轨按钮
控制栏 SHALL 提供字幕按钮与音轨按钮：字幕按钮点击 MUST 打开字幕选项，长按 MUST 显示 / 隐藏字幕；音轨按钮点击用于切换音轨。

#### Scenario: 点击字幕按钮
- **WHEN** 用户点击字幕按钮
- **THEN** 系统打开字幕选项

#### Scenario: 长按字幕按钮
- **WHEN** 用户长按字幕按钮
- **THEN** 字幕在显示与隐藏之间切换

#### Scenario: 点击音轨按钮
- **WHEN** 用户点击音轨按钮
- **THEN** 系统提供音轨切换

### Requirement: 片头片尾设置
控制栏 SHALL 提供片头、片尾、步长、重置按钮用于设置片头片尾：

| 按钮 | 点击 | 长按 |
| --- | --- | --- |
| 片头 | 把当前位置设为片头（只在前半段有效）；焦点在按钮上时用上 / 下键按步长调整 | 清除片头 |
| 片尾 | 把剩余时长设为片尾（只在后半段有效）；焦点在按钮上时用上 / 下键按步长调整 | 清除片尾 |
| 步长 | 片头片尾的调整步长，5s → 30s 循环 | 恢复为 5s |
| 重置 | 清除片头片尾 | 预设片头 110s、片尾 150s |

片头 MUST 只能在影片前半段设置，片尾 MUST 只能在影片后半段设置。

#### Scenario: 前半段设置片头
- **WHEN** 播放位置在影片前半段，用户点击片头按钮
- **THEN** 当前位置被设为片头

#### Scenario: 后半段点击片头无效
- **WHEN** 播放位置在影片后半段，用户点击片头按钮
- **THEN** 片头不被设置

#### Scenario: 后半段设置片尾
- **WHEN** 播放位置在影片后半段，用户点击片尾按钮
- **THEN** 当前剩余时长被设为片尾

#### Scenario: 前半段点击片尾无效
- **WHEN** 播放位置在影片前半段，用户点击片尾按钮
- **THEN** 片尾不被设置

#### Scenario: 用上下键按步长微调
- **WHEN** 焦点在片头或片尾按钮上，用户按上键或下键
- **THEN** 片头或片尾按当前步长增加或减少

#### Scenario: 长按清除
- **WHEN** 用户长按片头（或片尾）按钮
- **THEN** 片头（或片尾）被清除

#### Scenario: 调整步长
- **WHEN** 用户点击步长按钮
- **THEN** 步长在 5s 到 30s 之间循环切换
- **AND** 长按步长按钮时步长恢复为 5s

#### Scenario: 重置与预设
- **WHEN** 用户点击重置按钮
- **THEN** 片头与片尾都被清除
- **AND** 长按重置按钮时片头预设为 110s、片尾预设为 150s

### Requirement: 弹幕设置、屏显与横竖屏按钮
控制栏 SHALL 提供弹幕设置、屏显、横竖屏按钮：弹幕设置按钮 MUST 只在有弹幕时显示；屏显按钮控制右上角信息（时间、网速、分辨率、进度等）的显示 / 隐藏，并 MUST 保存该状态；横竖屏按钮用于竖屏视频（手机）切换方向。

#### Scenario: 有弹幕时显示弹幕设置
- **WHEN** 当前播放内容有弹幕
- **THEN** 控制栏显示弹幕设置按钮，点击打开弹幕设置

#### Scenario: 无弹幕时隐藏弹幕设置
- **WHEN** 当前播放内容没有弹幕
- **THEN** 控制栏不显示弹幕设置按钮

#### Scenario: 屏显状态保存
- **WHEN** 用户点击屏显按钮隐藏右上角信息后再次播放
- **THEN** 右上角信息保持隐藏

#### Scenario: 竖屏视频切换方向
- **WHEN** 在手机上播放竖屏视频，用户点击横竖屏按钮
- **THEN** 屏幕方向切换

### Requirement: 控制栏信息显示
控制栏 SHALL 在顶部显示片名与集名、系统时间、分辨率、网速，在底部 MUST 显示当前进度、总时长、「影片剩余」与「影片结束」时间。

#### Scenario: 显示控制栏
- **WHEN** 控制栏显示
- **THEN** 顶部显示片名、集名、系统时间、分辨率与网速
- **AND** 底部显示当前进度、总时长、影片剩余时间与影片结束时间

### Requirement: 解析列表
当存在多个解析接口时，控制栏 SHALL 显示解析列表，用户 MUST 能随时切换解析。

#### Scenario: 多个解析接口时切换解析
- **WHEN** 当前播放有多个可用解析接口
- **THEN** 控制栏出现解析列表
- **AND** 用户选择其他解析后系统改用该解析播放

### Requirement: 遥控器操作
系统 SHALL 按控制栏是否显示响应遥控器按键：

| 按键 | 控制栏隐藏时 | 控制栏显示时 |
| --- | --- | --- |
| 左 / 右 | 快退 / 快进，按住连续拖动 | 移动焦点 |
| 确定 / 播放暂停键 | 暂停 / 继续，暂停时自动显示控制栏 | 触发按钮 |
| 上 / 下 | 显示控制栏（上键会把焦点放到片头按钮） | 在倍速、片头、片尾按钮上调整数值 |
| 返回 | 先关闭控制栏，再退出播放 | — |

返回键 MUST 在控制栏显示时先关闭控制栏，而不是直接退出播放。

#### Scenario: 控制栏隐藏时左右键快进快退
- **WHEN** 控制栏隐藏，用户按左键或右键
- **THEN** 系统快退或快进
- **AND** 按住按键时进度连续拖动

#### Scenario: 控制栏隐藏时确定键暂停
- **WHEN** 控制栏隐藏且正在播放，用户按确定键或播放暂停键
- **THEN** 播放暂停并自动显示控制栏

#### Scenario: 控制栏隐藏时上键
- **WHEN** 控制栏隐藏，用户按上键
- **THEN** 控制栏显示且焦点位于片头按钮

#### Scenario: 控制栏显示时的按键
- **WHEN** 控制栏显示，用户按左 / 右键或确定键
- **THEN** 左 / 右键移动焦点，确定键触发当前按钮

#### Scenario: 返回键先关闭控制栏
- **WHEN** 控制栏显示，用户按返回键
- **THEN** 控制栏关闭，播放不退出
- **AND** 控制栏已关闭时再按返回键则退出播放

### Requirement: 控制栏自动隐藏
控制栏 SHALL 在 8 秒没有操作后自动隐藏。

#### Scenario: 无操作自动隐藏
- **WHEN** 控制栏显示后 8 秒内没有任何操作
- **THEN** 控制栏自动隐藏

### Requirement: 触屏手势
在手机 / 平板上，播放器 SHALL 支持以下触屏手势：

- 单击：显示 / 隐藏控制栏；
- 双击：左侧 1/3 快退 10 秒，右侧 1/3 快进 10 秒，中间暂停 / 播放；
- 长按：临时 3 倍速快进（当前已 ≥ 3x 则保持），松手后恢复原速；
- 横向滑动：调整进度；
- 左侧上下滑动：调整亮度；右侧上下滑动：调整音量。

长按松手后 MUST 恢复长按前的倍速。

#### Scenario: 单击切换控制栏
- **WHEN** 用户单击屏幕
- **THEN** 控制栏在显示与隐藏之间切换

#### Scenario: 双击不同区域
- **WHEN** 用户双击屏幕左侧 1/3
- **THEN** 快退 10 秒
- **AND** 双击右侧 1/3 时快进 10 秒，双击中间时切换暂停 / 播放

#### Scenario: 长按临时 3 倍速
- **WHEN** 当前倍速低于 3x，用户长按屏幕
- **THEN** 以 3 倍速播放，松手后恢复原倍速

#### Scenario: 长按时已高于 3 倍速
- **WHEN** 当前倍速已 ≥ 3x，用户长按屏幕
- **THEN** 保持当前倍速

#### Scenario: 滑动调整进度、亮度与音量
- **WHEN** 用户横向滑动屏幕
- **THEN** 播放进度随之调整
- **AND** 在左侧上下滑动调整亮度，在右侧上下滑动调整音量

### Requirement: 锁屏按钮
锁屏按钮 SHALL 只在非电视设备上显示；锁定后系统 MUST 屏蔽所有触摸操作。

#### Scenario: 锁定屏幕
- **WHEN** 在手机 / 平板上用户点击锁屏按钮锁定
- **THEN** 所有触摸操作被屏蔽

#### Scenario: 电视设备不显示锁屏
- **WHEN** 在电视设备上播放
- **THEN** 不显示锁屏按钮

### Requirement: 播放进度记忆
系统 SHALL 自动记录每一集的播放进度，再次播放该集时 MUST 从上次位置继续；「从头播放」MUST 清除该集进度。

#### Scenario: 续播
- **WHEN** 用户再次播放之前看过一部分的某集
- **THEN** 系统从上次记录的位置继续播放

#### Scenario: 从头播放
- **WHEN** 用户选择「从头播放」
- **THEN** 该集已记录的进度被清除，从头播放

### Requirement: 自动跳过片头与片尾
设置了片头时，系统 SHALL 在开播时自动跳过片头；设置了片尾时，播到片尾时间点 MUST 自动切到下一集。

#### Scenario: 开播跳过片头
- **WHEN** 影片设置了片头，开始播放某集
- **THEN** 系统自动跳过片头

#### Scenario: 播到片尾切集
- **WHEN** 影片设置了片尾，播放到片尾时间点
- **THEN** 系统自动切到下一集

### Requirement: 自动连播
一集播放完毕时，系统 SHALL 自动播放下一集。

#### Scenario: 播完自动下一集
- **WHEN** 当前集播放结束
- **THEN** 系统自动播放下一集

### Requirement: 出错自动重试
播放失败时，系统 SHALL 先在 IJK 与 Exo 之间切换内核再试；嗅探到多个候选地址时 MUST 依次尝试。

#### Scenario: 切换内核重试
- **WHEN** 使用 IJK（或 Exo）播放失败
- **THEN** 系统切换到 Exo（或 IJK）内核重试

#### Scenario: 依次尝试候选地址
- **WHEN** 嗅探得到多个候选地址且当前地址播放失败
- **THEN** 系统依次尝试下一个候选地址

### Requirement: 字幕来源
系统 SHALL 支持以下字幕来源：

- 内置字幕：选择视频自带的字幕轨（IJK / Exo）；
- 外挂字幕：爬虫返回的字幕地址、本地文件选择；
- 在线搜索：按片名在射手网（assrt.net）搜索并下载字幕。

在线搜索下载到压缩包时，系统 MUST 列出包内字幕供选择。

#### Scenario: 选择内置字幕轨
- **WHEN** 使用 IJK 或 Exo 播放带字幕轨的视频，用户打开字幕选项
- **THEN** 可以选择视频自带的字幕轨

#### Scenario: 外挂字幕
- **WHEN** 爬虫返回了字幕地址，或用户选择了本地字幕文件
- **THEN** 系统加载该外挂字幕

#### Scenario: 在线搜索压缩包字幕
- **WHEN** 用户在线搜索字幕并下载到压缩包
- **THEN** 系统列出压缩包内的字幕供用户选择

### Requirement: 字幕格式与调整
系统 SHALL 支持 SRT、ASS/SSA、SCC、STL、TTML 字幕格式，用户 MUST 能调整字幕大小、延迟（偏移）和样式，字幕选择结果按集缓存。

#### Scenario: 调整字幕
- **WHEN** 用户调整字幕大小、延迟或样式
- **THEN** 字幕显示按调整结果生效

#### Scenario: 字幕选择按集缓存
- **WHEN** 用户为某集选择了字幕后再次播放该集
- **THEN** 系统使用该集缓存的字幕选择

### Requirement: 音轨切换
系统 SHALL 列出当前视频的音轨并允许切换，IJK、Exo 和系统播放器 MUST 都支持。

#### Scenario: 切换音轨
- **WHEN** 使用 IJK、Exo 或系统播放器播放多音轨视频，用户选择另一条音轨
- **THEN** 播放切换到所选音轨

### Requirement: 弹幕加载
当爬虫在播放结果里返回弹幕地址（http 或本地 file）时，系统 SHALL 加载弹幕；画中画模式下 MUST NOT 显示弹幕。

#### Scenario: 返回弹幕地址
- **WHEN** 爬虫播放结果包含 http 或本地 file 弹幕地址
- **THEN** 系统加载并显示弹幕

#### Scenario: 画中画不显示弹幕
- **WHEN** 播放进入画中画模式
- **THEN** 弹幕不显示

### Requirement: 弹幕设置
弹幕设置 SHALL 提供以下设置项：弹幕开关、大小、行数、透明度、速度（超慢 / 慢 / 适中 / 快）、颜色（默认 / 随机）。

#### Scenario: 调整弹幕
- **WHEN** 用户在弹幕设置中修改开关、大小、行数、透明度、速度或颜色
- **THEN** 弹幕显示按新设置生效

### Requirement: 后台播放
`设置 → 后台` SHALL 提供「关闭」「开启」「画中画」三个选项。选「关闭」时离开页面 MUST 暂停；选「开启」时退到后台 MUST 继续播放。

#### Scenario: 后台关闭
- **WHEN** 后台设置为「关闭」，用户离开播放页面
- **THEN** 播放暂停

#### Scenario: 后台开启
- **WHEN** 后台设置为「开启」，用户退到后台
- **THEN** 继续播放
- **AND** 若是详情页内嵌播放器，通知栏显示上一集 / 播放暂停 / 下一集控制

### Requirement: 画中画
后台设置为「画中画」时，按 Home 键 SHALL 进入小窗播放，小窗里有上一集 / 播放暂停 / 下一集按钮；使用外部播放器时 MUST NOT 进入画中画。

#### Scenario: 按 Home 进入画中画
- **WHEN** 后台设置为「画中画」，用户在播放中按 Home 键
- **THEN** 进入小窗播放，小窗显示上一集 / 播放暂停 / 下一集按钮

#### Scenario: 外部播放器不进入画中画
- **WHEN** 后台设置为「画中画」但当前使用外部播放器，用户按 Home 键
- **THEN** 不进入画中画

### Requirement: 外部播放器
内核选 MX / Reex / Kodi 时，系统 SHALL 把播放地址和请求头交给对应的外部应用播放。

#### Scenario: 使用外部播放器
- **WHEN** 内核选为 MX Player、Reex 或 Kodi，用户开始播放
- **THEN** 系统把播放地址和请求头交给对应外部应用播放

### Requirement: HLS 预缓存
对于适用预缓存的 HLS 点播，系统 SHALL 改写 m3u8 列表，把每个分片地址指向本机的分片代理；再由分片代理按预缓存窗口，提前把分片下载到磁盘，供播放器读取。分片代理 MUST 只做透明的字节缓存：分片原样下载、原样存储、原样返回，不解密。播放器看到的效果 MUST 和直连源站一致：源站返回什么错误，就原样返回什么错误；预缓存自身出错时，只能降级为纯转发，不能让视频放不了。

改写规则：

- 只改写以 `#EXTM3U` 开头、带 `#EXT-X-ENDLIST`、至少有一个分片的单码率媒体列表。
- 每个分片 URI 行一对一替换成本机分片代理地址。分片的个数和顺序不变，`#EXT-X-MEDIA-SEQUENCE` 不变。
- `#EXT-X-KEY` 和 `#EXT-X-MAP` 的 URI 按 m3u8 地址补成绝对地址，标签的其余属性不变。
- 除上面两点外，其余行（包括空行和 `#EXT-X-DISCONTINUITY`）逐字保留。
- 请求源站时，带上播放时的原始请求头，每个值都去掉首尾空白。但 `Accept-Encoding`、`Range`、`Host`、`Connection`、`Content-Length` 这几个头（名字不区分大小写）不转发：分片代理总是请求完整分片，传输压缩由 HTTP 客户端自己协商并透明解压。解压后的字节就是源站返回的分片内容，所以仍然算原样下载、原样存储。

调度参数固定如下：

| 参数 | 取值 |
| --- | --- |
| 锚点 | 播放器最近一次请求的分片 |
| 预缓存窗口 | 从锚点开始往后 120 秒（按 `#EXTINF` 时长累加） |
| 回看保留 | 锚点往前 30 秒 |
| 并发下载 | 最多 3 个；被限流后为 1 个 |
| 每个会话的磁盘上限 | 300MB |
| 存储位置 | `<外部缓存目录>/hlscache/` |

同一时间 MUST 只有一个预缓存会话。

#### Scenario: 改写单码率媒体列表
- **WHEN** m3u8 以 `#EXTM3U` 开头，带 `#EXT-X-ENDLIST`，没有 `#EXT-X-STREAM-INF` 和 `#EXT-X-BYTERANGE`，并且有 N 个分片
- **THEN** 改写结果里的 N 个分片 URI 行按原顺序替换成 `http://127.0.0.1:<本地服务实际端口>` 开头的分片代理地址
- **AND** `#EXT-X-MEDIA-SEQUENCE`、`#EXTINF`、`#EXT-X-DISCONTINUITY`、空行等其余行和原文逐字相同

#### Scenario: 密钥和初始化段地址补成绝对地址
- **WHEN** m3u8 里的 `#EXT-X-KEY` 或 `#EXT-X-MAP` 带相对 URI
- **THEN** 改写结果里该 URI 按 m3u8 地址解析成绝对地址
- **AND** `METHOD`、`IV`、`KEYFORMAT`、`BYTERANGE` 等其余属性保持不变
- **AND** 播放器直接向源站请求密钥和初始化段，不经过分片代理

#### Scenario: 不适用的列表不改写
- **WHEN** m3u8 是 master 列表（含 `#EXT-X-STREAM-INF` 或 `#EXT-X-I-FRAME-STREAM-INF`），或者含 `#EXT-X-BYTERANGE`，或者含低延迟 HLS 的 `#EXT-X-PART` 或 `#EXT-X-PRELOAD-HINT`，或者没有 `#EXT-X-ENDLIST`，或者不以 `#EXTM3U` 开头，或者没有任何分片，或者 m3u8 地址不是 `http://` 或 `https://` 开头
- **THEN** 系统不改写该列表，也不开始新的预缓存会话
- **AND** 之前的预缓存会话结束，它的分片从磁盘删除

#### Scenario: 命中预缓存
- **WHEN** 播放器请求的分片已经完整下载到磁盘
- **THEN** 分片代理从磁盘读取该分片，返回 200，不再请求源站

#### Scenario: 未命中预缓存
- **WHEN** 播放器请求的分片不在磁盘上，也没有在下载
- **THEN** 分片代理立即从源站下载该分片，一边下载一边返回给播放器，同时写入磁盘
- **AND** 这次下载不受并发上限和磁盘上限的限制

#### Scenario: 分片文件被外部删除
- **WHEN** 已下载的分片文件被外部删除后，播放器再次请求该分片
- **THEN** 系统按未命中处理，重新从源站下载

#### Scenario: 同一分片的并发请求
- **WHEN** 某个分片正在下载（无论是预缓存还是另一个播放器请求触发的），又有请求要这个分片
- **THEN** 系统不重复向源站请求，后来的请求等待同一次下载，按下载进度拿到数据
- **AND** 所有请求拿到的字节和源站返回的完全一致

#### Scenario: 源站返回 HTTP 错误
- **WHEN** 源站对分片请求返回非 2xx 状态码（如 403、404、503）
- **THEN** 分片代理向播放器返回同一个状态码
- **AND** 该分片不写入磁盘

#### Scenario: 请求源站时去掉的请求头
- **WHEN** 播放时的请求头里有 `Accept-Encoding`、`Range`、`Host`、`Connection` 或 `Content-Length`（名字不区分大小写）
- **THEN** 系统回源时不带这些头，其余请求头去掉首尾空白后照常带上
- **AND** 源站用压缩编码返回时，系统存储和返回的是解压后的分片字节，播放器看不到 `Content-Encoding`

#### Scenario: 预缓存失败的分片不自动重试
- **WHEN** 某个分片的预缓存下载失败（源站返回非 2xx、没有拿到 HTTP 响应，或者长度和 Content-Length 不符）
- **THEN** 本次会话不再自动预缓存这个分片
- **AND** 播放器请求到这个分片时，按未命中处理，从源站重新下载

#### Scenario: 源站无法连接
- **WHEN** 请求源站时没有拿到 HTTP 响应（连接被拒、超时、DNS 失败等）
- **THEN** 分片代理向播放器返回 502

#### Scenario: 磁盘写入失败时降级为纯转发
- **WHEN** 预缓存会话中创建、写入或提交分片文件失败
- **THEN** 本次会话停止所有预缓存下载
- **AND** 之后每个分片请求都直接转发源站的响应，不再读写磁盘，直到会话结束

#### Scenario: 按窗口预缓存
- **WHEN** 播放器请求了第 k 个分片
- **THEN** 第 k 个分片成为锚点
- **AND** 系统按顺序下载开始时间距锚点不足 120 秒、还没有下载的分片，同时最多 3 个下载

#### Scenario: 暂停时填满窗口后停止
- **WHEN** 播放器暂停，不再请求新分片
- **THEN** 系统继续下载，直到窗口内的分片都已下载，然后停止

#### Scenario: 回看淘汰
- **WHEN** 锚点前移到第 k 个分片
- **THEN** 开始时间比锚点早 30 秒以上的分片从磁盘删除
- **AND** 开始时间比锚点早 30 秒以内的分片保留，再次请求时直接命中

#### Scenario: 跳转
- **WHEN** 播放器请求的分片既不是当前锚点，也不是锚点的下一个分片
- **THEN** 系统按新锚点重新计算窗口
- **AND** 取消新窗口之外正在进行的预缓存下载，删除新窗口和回看范围之外的已下载分片
- **AND** 从新锚点开始预缓存

#### Scenario: 达到磁盘上限
- **WHEN** 本次会话已存储的分片，加上正在下载的分片预计大小，再加上下一个分片的预计大小，会超过 300MB
- **THEN** 系统先删除锚点之前的回看分片来腾出空间
- **AND** 腾出空间后仍然超过时，不再开始新的预缓存下载，窗口相当于缩短到已下载的位置；锚点前移、释放出空间后再继续

#### Scenario: 被限流时降为单线程
- **WHEN** 同一会话里累计 3 次请求源站时遇到 429、503、403 或连接被拒
- **THEN** 本次会话的并发下载数降到 1，播放器请求触发的下载也计入这个并发数
- **AND** 本次会话内不再恢复到 3 个

#### Scenario: 同一 m3u8 地址复用已下载的分片
- **WHEN** 开始新的预缓存会话时，m3u8 地址和上一个会话相同
- **THEN** 新会话复用上一个会话已下载的分片，命中的分片不再请求源站
- **AND** 上一个会话正在进行的下载被取消，上一个会话的分片代理地址失效

#### Scenario: 不同 m3u8 地址或离开播放页时清空
- **WHEN** 开始新的预缓存会话时 m3u8 地址和上一个会话不同，或者离开播放页时结束会话
- **THEN** 上一个会话的下载全部取消，它的分片从磁盘删除

#### Scenario: 只结束自己建的会话
- **WHEN** 播放页结束会话时说明「结束我建的会话」，而当前会话是后来另一个播放页建的（比如旧页面的销毁晚于新页面开始播放）
- **THEN** 当前会话不受影响，继续预缓存，它的代理地址仍然有效
- **AND** 只有当前会话正是这个播放页建的时，才按「离开播放页」结束它
- **AND** 按「结束我建的会话」请求、却没有给出播放页标识时，什么都不结束（无条件结束会话的请求不受这条限制）

#### Scenario: 请求已失效的会话
- **WHEN** 播放器用已结束或已被替换的会话的分片代理地址请求分片
- **THEN** 分片代理返回 410，不请求源站

### Requirement: 预缓存的作用范围
`设置 → 预缓存` 开启时，全屏播放页和详情页小窗播放器 SHALL 对经过普通点播流程的 HLS 播放启用预缓存（改写规则、调度与会话复用见「HLS 预缓存」）：系统先下载 m3u8；如果它是只含一个子列表的主列表，再下载一次子列表；然后把最终要播的那份列表交给预缓存改写。交给改写的内容规则如下：

| 广告过滤 | 净化结果 | 交给改写的内容 |
| --- | --- | --- |
| 开启 | 成功 | 净化后的内容 |
| 开启 | 失败（无法净化） | 原文 |
| 关闭 | 不净化 | 原文 |

改写成功时，播放器 MUST 通过本地服务的 `/m3u8` 地址播放改写后的列表；该列表不适用预缓存时，系统 MUST 按未开启预缓存时的逻辑播放（广告过滤开启且净化成功时播放净化后的列表，否则播放原地址），不能因为预缓存导致视频放不了。

以下播放 MUST NOT 使用预缓存，交给播放器的地址 MUST 和未开启预缓存时完全一致：

- `设置 → 预缓存` 关闭（默认）；
- 当前内核是外部播放器（MX、Reex、Kodi）；
- 直播；
- 「特殊链接直接播放」列出的链接：存储空间里的视频（`tvbox-drive://`）、迅雷类链接（磁力、`thunder://`、`ed2k://`、`.torrent`、`ftp://`）、荐片链接（`xg://`、`xgplay://`、`tvbox-xg:`）、分段 mp4；
- 地址里既不含 `.m3u8`、也不含 `://127.0.0.1/` 的普通直链。

预缓存会话 MUST 在离开播放页时结束。后台播放、画中画、详情页小窗与全屏之间切换 MUST NOT 结束会话。开始播放一个不使用预缓存的内容时，系统 MUST 结束上一个预缓存会话。

#### Scenario: 开关关闭时不改写
- **WHEN** `设置 → 预缓存` 为关闭（包括从未修改过），用户播放一个 HLS 点播
- **THEN** 系统不改写 m3u8，不开始预缓存会话
- **AND** 是否下载 m3u8、是否去广告、交给播放器的地址都和没有预缓存功能时完全一致

#### Scenario: 开关打开时两个播放入口都走预缓存
- **WHEN** `设置 → 预缓存` 开启，用户在全屏播放页或详情页小窗里播放一个适用预缓存的 HLS 点播（带 `#EXT-X-ENDLIST` 的单码率媒体列表）
- **THEN** 播放器通过 `http://127.0.0.1:<本地服务实际端口>/m3u8` 播放
- **AND** 该列表里的每个分片地址都指向本机的分片代理

#### Scenario: 跟随一次子列表后改写子列表
- **WHEN** `设置 → 预缓存` 开启，下载到的 m3u8 是只含一个子列表的主列表
- **THEN** 系统下载该子列表，并以子列表的地址作为 m3u8 地址交给预缓存改写

#### Scenario: 去广告关闭时也改写
- **WHEN** `设置 → 预缓存` 开启，`设置 → 广告过滤` 关闭，用户播放地址含 `.m3u8` 的点播
- **THEN** 系统先下载 m3u8，再把原文交给预缓存改写
- **AND** 改写成功时播放器通过本地 `/m3u8` 播放，列表里的广告分片不做删除

#### Scenario: 净化失败时也改写
- **WHEN** `设置 → 预缓存` 和 `设置 → 广告过滤` 都开启，m3u8 无法净化
- **THEN** 系统把 m3u8 原文交给预缓存改写
- **AND** 改写成功时播放器通过本地 `/m3u8` 播放

#### Scenario: 净化成功时改写净化后的内容
- **WHEN** `设置 → 预缓存` 和 `设置 → 广告过滤` 都开启，m3u8 净化成功
- **THEN** 系统把净化后的内容交给预缓存改写，广告分片不会出现在改写后的列表里

#### Scenario: 列表不适用时按原逻辑播放
- **WHEN** `设置 → 预缓存` 开启，最终要播的列表不适用预缓存（如多码率主列表、带 `#EXT-X-BYTERANGE`、没有 `#EXT-X-ENDLIST`），或者下载 m3u8 失败
- **THEN** 广告过滤开启且净化成功时，播放器播放净化后的本地 `/m3u8`
- **AND** 其余情况播放器播放原地址（跟随过子列表时为子列表地址；下载失败时为最初的地址）

#### Scenario: 外部播放器不改写
- **WHEN** `设置 → 预缓存` 开启，当前内核是 MX、Reex 或 Kodi，用户开始播放
- **THEN** 系统不改写 m3u8，交给外部播放器的地址和请求头和未开启预缓存时完全一致
- **AND** 上一个预缓存会话结束

#### Scenario: 直播等特殊链接不走预缓存
- **WHEN** `设置 → 预缓存` 开启，用户观看直播，或者播放存储空间里的视频、迅雷类链接、荐片链接、分段 mp4
- **THEN** 系统不改写，不开始预缓存会话，交给播放器的地址和未开启预缓存时完全一致

#### Scenario: 普通直链不下载 m3u8
- **WHEN** `设置 → 预缓存` 开启，`设置 → 广告过滤` 关闭，播放地址既不含 `.m3u8` 也不含 `://127.0.0.1/`
- **THEN** 系统直接播放原地址，不下载、不改写

#### Scenario: 切集、重播与切内核重试重新改写
- **WHEN** `设置 → 预缓存` 开启，用户切到上一集或下一集、点重播，或者播放出错后系统切换内核自动重试
- **THEN** 系统重新走一遍下载与改写，由新的改写决定复用还是清空上一个会话的分片
- **AND** 新的播放内容不使用预缓存时，上一个会话结束

#### Scenario: 离开播放页时结束会话
- **WHEN** 用户从全屏播放页返回，或者离开带小窗播放器的详情页
- **THEN** 当前预缓存会话结束，下载全部取消，它的分片从磁盘删除

#### Scenario: 旧页面晚到的销毁不影响新页面的会话
- **WHEN** 系统先关闭旧的详情页、再打开新的详情页（后台设置为「画中画」时打开另一部影片的详情页，或者收到推送打开详情页），新页面已经开始预缓存之后，旧页面才完成销毁
- **THEN** 新页面的预缓存会话继续，播放器仍然能正常拿到它的分片
- **AND** 旧页面销毁时只结束它自己开始的预缓存会话

#### Scenario: 后台播放、画中画不结束会话
- **WHEN** 后台设置为「开启」时用户退到后台继续播放，或者后台设置为「画中画」时用户按 Home 键进入画中画
- **THEN** 预缓存会话继续，回到播放页或在画中画里继续播放时仍然使用已下载的分片

#### Scenario: 关闭画中画小窗时结束会话
- **WHEN** 全屏播放页处于画中画，用户关闭画中画小窗，播放器随之释放
- **THEN** 当前预缓存会话结束

#### Scenario: App 启动时清空预缓存目录
- **WHEN** App 启动，外部缓存目录下的 `hlscache/` 里留有上一次进程的会话目录（比如进程被杀，会话没有正常结束）
- **THEN** 启动过程中 `hlscache/` 被清空，之后开始的预缓存会话不会用到旧的分片
- **AND** 旧内容的删除在后台进行，不在主线程逐个删除文件，App 启动不因此卡住
- **AND** 以前几次启动没有删完的旧内容也一起删除

#### Scenario: 详情页小窗照常预缓存
- **WHEN** `设置 → 预缓存` 和 `设置 → 窗口预览` 都开启，用户进入详情页，小窗自动开始播放 HLS 点播
- **THEN** 小窗播放同样走预缓存
- **AND** 小窗与全屏之间切换时，会话不结束，播放不重新改写
